# 第三馆 · 绘世厅与佛法厅

## 局域网试玩

入口是 `mogao-exhibit-v001.html`。每次点「上楼」先停在下一层的厅门外。两厅各自以实际打开过壁画故事或展品为分界。未点选过时，从楼梯抵达会看题、自动步入并展示介绍。有点选记录后，玩家自行入厅。楼梯辅助在楼梯及楼梯厅内显示，手机横屏靠底边排列。「观看沙弥故事」留在一层观画区。`?view=hall-b` 可直达厅内，使用同一个观展记录。初玩需看完十二件才能由佛法厅走上本层的观佛高台。

## 二层 A 厅 · 绘世厅

`?view=hall-a` 可直达绘世厅。楼梯侧外门楣以暗金卷草衬托直接贴面的黑体「绘世厅」，厅内原浅米色牌保留。《五百强盗成佛图》贴近 D 墙首段画幅，题字下右齐标出「莫高窟第285窟 · 西魏」。《火宅喻》与「莫高窟第61窟 · 五代」位于壁画上方，两行都与画幅左沿对齐。两组题字用暖金黑体。 [第285窟](https://www.dha.ac.cn/info/1425/3698.htm) · [第61窟](https://www.dha.ac.cn/info/1425/3588.htm)

长卷沿 D、A、B 三墙连展，画高 4.31 米。《火宅喻》单独布在观佛口右侧 C 墙，画幅 7.02 × 3.60 米。深灰棕墙面配暖白轨道射灯。点击原画或题名展开故事。全图导语与放大后的局部讲解期间，点画面即可跳过当前讲解，直接进入下一处画框。展开、画框、推近和自动退回由演出接管。A 厅沿用短字幕，回到全图时一次呈现完整结语。九色鹿和沙弥沿用现行旁白，末段返回全图后可重看或回到原站位。

首次从楼梯抵达时，角色抬头看厅名 2.5 秒，再沿通道自动步入。介绍含三句总览、点选壁画说明和观佛口解锁提示，点「开始浏览」恢复漫游。重访使用同样的信息框样式，可边走边看，点壁画或题名即收起。佛法厅沿用同一流程，直达与厅内恢复使用非阻塞介绍。

两幅全图在踏上第一段楼梯时补载，手机档合计约 265 KiB。九张局部图按当前故事段加载。供稿原图、坐标和文案登记于 `art-source/world/mogao-hall-a/v001/`，运行 WebP 可用 `scripts/prepare-mogao-hall-a-v001.py` 复现。A 厅专项浏览器验证使用 `MOGAO_EXHIBIT_LAYOUT=v004 MOGAO_EXHIBIT_TARGET=hall-a node scripts/verify-mogao-exhibit-v001.mjs`，证据见 `work/world/mogao-exhibit-v001/hall-a-v001/`。

电脑与手机横屏 Chromium 验证了门楣点选、两部故事共九段、结语、回退及关闭恢复站位。手机直达 B 厅时未请求 A 厅图像，B02 可照常打开。WebKit 手机横屏补测了首次点画、局部和原位恢复。实景和请求记录见 `hall-a-v001/browser-2026-11-06T21-07-55-974Z/report.json` 与 `hall-a-v001/mobile-webkit-story.json`。

## 三层 B 厅 · 佛法厅

从楼梯侧可在现有檐底读到黑体「佛法厅」，门墙饰暗金卷草。厅内入口侧的展览牌题为「佛像里的千年敦煌」。

按楼梯口面向厅内的方向，A 左墙、B 正对、C 右墙、D 入口侧。A 的主题在两组挂画之间竖排。B 三幅高挂并为右起竖排的主题留位，C 主题沿用左上横排，B/C 的主副字号与 A/D 一致。C 的新版千手观音整图和手部特写叠放在右列。D 三幅画的图边水平净距均为 0.45 米，楼梯口左上保留卷草细边的浅米色拉丝牌匾，牌体厚 8.2 厘米。B/C 的灯轨贴近折顶并缩短灯头吊件。画框和标题共用墙面布局数据，裁幅只用于墙面呈现。

洞窟楼道、梯道和展厅的室内墙面统一为深灰棕，梯道和出入口保留行走照明，B 厅逐幅照亮展图。四墙资源从第三段楼梯开始加载。点整图或特写可分别打开对应大图，千手观音的两面合计为一件。关闭后恢复原位。

一层楼梯厅灰棕地面覆盖到岩腔边，梯厅墙面和墙脚连成一体。二层楼梯平台的门侧补齐接缝。两厅观佛口门脚的地面接合采用独立边界，避免共面闪烁。 [入场方案](./mogao-exhibit-entrance-plan-v001.md)

四墙的宋体副标题加粗，正下方各有一枚约一个副题字高的镂空金线莲花，点击显示该墙的主题导语。莲花不计入十二件展品，首次入厅文字先提示寻找莲花，再提示点击展品。新版标题和纹样保存在 `mogao-exhibit/v005/`，墙面配置使用 `mogao-exhibit-layout-v004.json`。

手机横屏的大图用左图右文，整图按比例贴合可用区域。讲解独立滚动，出处和关闭留在右栏。展图可用双指连续缩放，放大后单指拖动。桌面支持滚轮和加减键缩放，方向键平移，按 0 恢复整图。

B 厅观佛口向展厅伸出的门楣由 90 厘米收至 14 厘米，外露厚度由 20 厘米减至 10 厘米。门楣和镜头遮挡共用薄边尺寸，洞内保留 3.10 米净高。

## 观展门禁与奖励

- 12 个稳定展品 ID 存在独立的本地进度键。点击成功即计入，重复点击、缺图和顺序差异不影响其他展品。锁定时，B 厅高台洞口的金光、人物碰撞和相机碰撞使用同一位置与状态。上层预览的直达参数和保存恢复也服从门禁。
- A 厅两部故事播完结语、回到漫游后，才开启本层观佛口，发放《绘世观壁笺》。B 厅完成第 12 件并关闭大图后，才开启本层观佛口，发放《敦煌观展手卷》。两厅进度独立，直达或刷新均核对对应门禁。
- 观佛口解锁即开始加载所需的洞内模型，金光按原时长退去。在模型尚未到齐时，门洞暂呈暗处，实景就绪即自动显露。两厅都可在原站位观察这个变化。
- 首次开门后，奖励在屏幕中心伴着动态金色环光出现。点卷轴可展开，也可直接收下。领奖和「我的图鉴」共用同一张卷轴图，名称区分内容。合上后从右上角「我的图鉴」重读，已领取的旧 B 厅手卷也在其中。图鉴打开期间暂停漫游，关闭后原地恢复。
- 《绘世观壁笺》先收录一楼主室的《九色鹿王本生》《沙弥守戒》，再收录二楼绘世厅总览和《五百强盗成佛图》《火宅喻》。四部均标明楼层和出处，保留全图、开场和各段原讲解，二楼另有结语。阅读缩略图只在观壁笺打开并滑到附近时加载。
- 手卷按总览、A/B/C/D 主题、每墙三件图文组织。正文可选择、可滚动。展开后才加载进入滚动区域的缩略图，12 张最长边 240 像素的 WebP 共 **137,730 字节**。

新版端到端证据存 `work/world/mogao-exhibit-v001/hall-a-completion-v001/`。A 厅在桌面与手机横屏自动走完两部故事，以加速浏览器时钟核对各段、暂停和结语。B 厅在桌面和手机横屏从十二次点展品实走到高台。另测 640×255 的主游戏图鉴、两份牛皮纸、旧 B 档和减弱动态设置。

最新点按规则和统一卷轴图的证据存 `work/world/mogao-exhibit-v001/mural-skip-v001/`。四部在桌面鼠标和手机横屏触控分别复核了开场跳过、转场保护、局部语音或字幕停止和直接进入下一处画框。图鉴列表和两厅领奖的图源均为 `mogao-exhibit/v001/reward-scroll.webp`。

整段结语、两厅原位看见门洞开放、慢速加载和重试的验证存 `work/world/mogao-exhibit-v001/mural-ending-v001/`。在四部壁画上验证了结语整段同屏并可点按结束。观佛口测试使用延迟洞内模型响应，领完奖励后人物和镜头留在原位，先看到暗色门洞，资源放行后出现洞内实景。
