# 《九色鹿王本生》画廊排序方案（已确认）

> 后续试玩修订：缩略图相邻贴合，拖起后其余画面补位；完成后整幅长卷由下向画面中央渐入放大，随后出现返回、下一关和重玩，没有下一实际关时禁用下一关。手机竖屏中断保留本局并取消未完成拖动。独立 2D 分支从主题入口进入，完成后返回 2D 游戏流程。

## 范围与素材

将壁画故事主题中的《九色鹿王本生》从当前 2 行 6 列、不规则碎片拼图，改为画廊式横向排序。继续使用当前 4096×682 的长卷原图，按从左到右等宽切成 12 个纵向画面；分片数量写入关卡配置，以后可调整。切片只改变展示和取样，不重绘原画。纹样主题的其他拼图不改玩法。

## 界面与操作

- 手机横屏和电脑使用相同的画廊结构：上方大图显示当前选中的一幅，保持完整比例；下方横向排列乱序缩略图，容纳不下时仅缩略图栏横向滚动。
- 点击缩略图只切换上方大图；按住某一缩略图拖至其他两幅之间，显示插入位置，松手后插入，其他画面自动让位。拖到最前或最后也能插入；拖近缩略图栏边缘时自动滚动。手机区分滑动浏览、点击和按住拖动，不误触排序。
- 不把原图碎片压到一屏，也不让整页滚动；重要画面和必要操作同屏。保留适合键盘和不能拖拽的玩家的选中、左右移动操作，并在窄屏不遮挡主图。
- 开局随机打乱，避免直接生成正确顺序；依画卷原本从左到右的相邻顺序判定，全部排对后完成。此画故事从两端向中间展开，叙事先后与画面左右排列不同，游戏明确要求恢复画面顺序。玩法不限时，可重试；提示和查看原图沿用现有游戏风格，避免额外说明型弹窗。
