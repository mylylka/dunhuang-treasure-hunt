# 莫高窟砂岩游戏接入 v007

用户已确认独立整山砂岩材质样片并要求继续。本轮接入独立可玩预览，保留正式入口、全部旧版本与已验收的源资产。

## 范围与目录

- 复用 `mogao-sandstone/v001/mountain.glb`、`mogao-massing/v003/tower.glb`，维持楼高45米、人物展示高度1.8米。
- `art-source/world/models/mogao/v007/` 保存入口衔接源工程和导出登记；`public/assets/world/mogao/v007/` 保存衔接模型。以新文件将静态展示用暗色封板改为真正可通过的短通道，旧foundation不覆盖。
- `scripts/build-world-mogao-v007.py` 离线提取网格碰撞、积沙高度与入口尺寸；`src/content/world/mogao-layout-v007.json` 及 `mogao-geometry-v007.json` 保存共享运行数据。Three.js不生成山体外形。
- `src/world/mogao-*-v007.ts`、`mogao-v007.html` 为独立入口；`outputs/mogao/v007/` 为构建，4214为预览端口，独立session键。
- `tests/world/mogao-v007.test.ts` 和 `scripts/verify-mogao-v007.mjs` 验证实际通行；`work/world/mogao-v007-*` 保存截图、日志与检查，不自动清理。

## 验证

核对新山体、积沙、45米楼体与现有内室的真实位置，重建匹配的新版本台阶高度和碰撞；验证石板路到台阶、中央入口、四面壁画室及返回路线，检查镜头转向、抬头、九色鹿播放与退出。运行规则测试、类型检查、内容检查、独立生产构建及真实浏览器回归。原山体、九层楼、角色、内室和旧GLB的SHA保持一致。

## 已完成（2026-11-02）

- 独立可玩入口：`http://localhost:4214/`；可用 `?view=overview`、`?view=oblique`、`?view=steps`、`?view=interior` 定位验收。正式入口及旧版本保留。
- 已加载验收通过的完整砂岩GLB与45米九层楼，场景中外部模型使用地面原点，原内室保持6.85546875米高程。角色仅在此预览按Idle实际包围盒归一至1.8米，原GLB和动画不修改。测量时暂归零父节点，避免高台初始位置被计入模型脚底偏移。
- 新版入口GLB包含原尺度台阶与基座、短通道地面及两侧内衬、上方遮挡背板。原展示封板未进入此导出；上方背板隔开楼层缝隙与壁画室，实际入口保持畅通。
- 台阶实际为宽10.4米、长19米、30级、总高6.855米。碰撞匹配缩放后柱位与6.08米通道；运行按连续坡面行走，并拒绝从高台阶侧边直接跳变到低处。
- 离线提取103段岩体前缘代理和192个积沙三角形；游戏逐三角面求积沙高度，地面与山脚同色。扩大底层沙地平面以覆盖整山和镜头活动范围，没有重排地图道路或建筑。
- 保持原太阳方向、强度与天空光；进入莫高窟区域时仅扩大同一盏太阳灯的阴影包围范围，容纳58米山体与塔。三组砂岩贴图启用各向异性过滤。
