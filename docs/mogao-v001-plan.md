## 外部造型与到达节奏

1. 从乐舞馆院门外延续现有不规则石板路，向更远的右后方绕行。第一版目标为从乐舞馆门外至窟前平台约65—75秒正常步行，含台阶；沿途依次看到崖顶、完整崖面、主入口。路线逐渐揭示，不要求全程遮住庞大崖壁。
2. 初步区域锚点设在旧区域东北方：窟口约X=122、Z=-68，崖面横向伸展。路径从(40.2,8)向(69,14)、(91,4)、(105,-20)、(122,-52)推进，再登阶。坐标是布局草案，实际要检查路长、旧围墙、沙丘、完整路宽及镜头扫掠范围。
3. 崖体在Blender里按大层理和阶状退台制作；先设计宽厚主形、深浅错落的大崖面，再加少量风化凹凸。窟口实际凹入岩体，不能是贴在平板上的黑方块。窟檐与洞口岩体严密接合。
4. 首版1处完整可进入主窟，约10—14处高低错落的背景窟口，少量窟檐、上下栈道和栏杆；背景窟口不开放行走，避免额外室内制作开销。排列有疏密，不能整齐贴成重复立面网格。
5. 砂岩暖赭、木构朱砂与灰蓝顶，面向光的岩面和背光退台形成清楚的大明暗。沿路复用已确认树灌木，不新增尖刺草丛，不重新随机生成山峰。

## 窟内造型、装饰与光照

- 第一眼要同时读到厚重的入口、中央柱体、柱后空间与高处顶面；室内墙面保持可阅读的大面，中央柱体转角有体积，不复制乐舞馆的外墙板式布局。
- 地面为平整大石板，尺度稳定、细缝；台座、墙裙、主壁画、上部装饰带、顶面分层组织，避免14m高空墙只有一条孤立长卷。
- 西壁只放一幅连续九色鹿原长卷，不将六段局部分别贴成六幅墙画。留6m以上的退观距离，主室24m宽足以侧移完整观看和绕柱。
- 保留暖砂岩、赭红、石绿/灰蓝的有限色系。入口侧光照亮一部分地面与柱体，内部整体略暗但主壁画可读；不靠强雾、过曝、额外泛光遮盖造型问题。外壳遮光与内部照明分区避免太阳穿墙照亮整个洞窟。
- 不把透视场景整图当贴图，不把真实裂缝逐条建模。纹样和壁面细节优先使用合理尺寸的烘焙贴图，柱体、龛口、边框承担真实几何体积。

## 制作阶段和验收

方案确认后，第一步交付一段完整可走的洞窟样片：道路接近→登阶→入窟→绕中央柱→西壁观察→返回漫游。Blender工程保留，导出GLB并在真实网页第三人称镜头中验收。

空间与美术方向通过后再完善六段故事：核对局部与全卷对应、正文、既有本机配音试听渠道和时间线，沿用刚确认的纯字幕、空格跳过、最后中央两项选择。当前两段技术预览不能冒充六段正式内容；这次先不追加新的小游戏或未完成的stories导览。

验证包括：旧资产SHA、旧入口回归；新道路全宽/登阶/墙柱与镜头碰撞、出入窟照明、视角抬头后恢复、暂停失焦/横竖屏、文化事件退出/返回点、资源错误重试、区域按需加载释放、手机横屏模拟。新区域初步预算为35万三角形以内、约100个材质批次以内，最终用真实浏览器记录峰值；预算不是画质验收通过的替代。
