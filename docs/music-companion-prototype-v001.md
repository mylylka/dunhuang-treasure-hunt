# 第二馆并排导览者原型 v001

2026-11-04。按用户“先检查架构、给出简短实施方案，再实现和测试”的要求增量开发；原型仅在独立入口启用。

## 架构与实施范围

现有`art-sample.ts`负责GLB加载与归一化、玩家AnimationMixer和资源释放，`runtime.ts`负责键盘、位移、相机及生命周期，React `WorldScreen`负责界面。第二馆现行世界采用music v006行为/v004建筑，并另行搬移家具和大树根；同行者须使用当前`terrain-rules-v001.ts`的碰撞，避免追向旧家具坐标。

1. 在同一次小旅人GLB加载上以SkeletonUtils克隆独立骨架，保持独立Idle/Walk/Run mixer；共享几何和材质仅由原加载资源释放。
2. 第二馆平坦庭院以简单网格寻路及实际移动碰撞跟随，按用户追加要求侧前方并排行走：横向1.6米、领先0.4米，合距约1.65米；远距有限加速靠近。玩家停步时立即停下；避让家具和玩家，玩家倒退时也保持身体间距。
3. 玩家进入指定区域，同行者停止并面向玩家。测试句为临时对白，字幕配浏览器合成语音，不增加音频或美术素材。语音不可用/静音时保留字幕，结束或主动关闭后恢复跟随。
4. 暂停、失焦、隐藏和离页停止，清理语音与角色资源；不改变原玩家输入或相机，不扩展到楼梯或跨层寻路。

入口`music-companion-v001.html`，会话键`dunhuang:music-companion:v1`。原型配置、纯行为、人物呈现分别独立维护。只跑相关规则/动画/对话检查、实际浏览器操作、类型和入口构建。

## 实现

- 小旅人模型仅加载一次，克隆独立骨架与Idle/Walk/Run动画混合器；两人归一化身高均为1.8米。共享模型、贴图、材质不修改，不新增美术或音频文件。临时角色不加入静态烘焙阴影，避免移动后遗留影子。
- `companion-follow.ts`负责并排目标、启停、追赶、对白与人物间距；`companion-navigation.ts`在约定平地内以0.45米网格寻路，路径逐段复用当前地形碰撞检查。正常槽位被家具占据时寻找邻近安全站位，绕障时可以暂时离开并排位置。
- 急转弯被同行者挡住时，控制器消费本帧有效移动意图，先让NPC安全调整站位，避免“玩家碰撞停下→NPC也停下”的互锁；松键、暂停或单纯撞墙不继续让行。玩家身体朝向、相机和输入模块保持原实现。
- 正常侧向1.6米、前向0.4米；步行速度上限2.6米/秒，同步跑步上限7.4米/秒，超过4米可用7.6米/秒追赶，单步和总帧时长均有限制，不瞬移。人物中心间距至少约1.4米。
- 玩家出生于第二馆源坐标(44,-4)，临时导览者出生于(44.4,-5.6)；进入地面圆环中心(50,-5)、半径1.2米时触发测试句。测试对白原生语音结束或点击“结束对话”即结束；无可用语音时字幕保留约5秒，离开后再次进入才重触发。
- 会话与默认世界隔离。刷新原型从两人共同起点开始，默认首页仍使用原会话且不启用NPC。玩家原键盘、相机和交互入口继续使用现有模块。

## 同步跑步修订（2026-11-04）

用户要求玩家跑时同行者也跑。运行时将既有`control.run`传给同行者：电脑Shift和手机摇杆幅度>0.82共用同一信号，玩家7米/秒的速度保持。同行者同步跑步上限7.4米/秒，支持追回轻微编队误差；远距追赶上限仍为7.6米/秒，普通并排跑不标为chasing。动画按实际速度>4米/秒使用原GLB的真实Run片段和玩家同一播放倍率标定，走→跑→走→停均平滑切换，不改模型。

专项测试现为23项（follow 13、avatar 3、speech 7），类型检查与原型入口构建通过。补测连续8.75米跑步并排、跑→走→停和真实庭院/琵琶架外围跑步绕障。浏览器电脑W→Shift→松Shift→松W实测，两人均Walk→Run→Walk→Idle；跑步时NPC约7.4米/秒，中心距1.645米。844×390横屏触控模拟使用真实触点拖摇杆：半幅→满幅→半幅→松手，两人同样切换上述动画，跑步中心距1.643米；未进行实体手机扬声器或性能实测。
