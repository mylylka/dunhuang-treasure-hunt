# 第二馆二楼装修衔接

乐器厅后墙与楼梯间壁画在实际墙端相接处增加深赭红窄木包边和一条细暗金线。构件贴靠原墙，不跨楼梯开口，不新增碰撞或拾取目标。楼梯间及有顶露台的顶面与乐器厅使用同色米白饰面；原屋顶和壁画保留，乐器厅原有几何浮雕仍可见。顶面采用连续饰面，避免接缝亮线。

乐器厅两墙和前廊延续段的顶部装饰带上移 0.275 米至天花，绿色墙裙及其上方收边等量加高；浮雕框和乐器保持原位置。

新增部件随接近楼梯和二楼按需加载。验收记录与实景截图在 `work/world/music-transition-v001/`，独立构建在 `work/world/music-transition-build-v001/`。已从真实入口在电脑和模拟手机横屏实走，往返楼梯接口，并在接缝附近点开笛子试听；相关定向测试共 25 项通过。手机为浏览器模拟，非实体手机实测。
