## 2. 产品总设计与不可退回的决定

这是本地优先的网页文化小游戏，主要用户为高中生，文化科普可以有深度。没有账号、服务端、数据库、云同步；各浏览器独立保存。用户负责在ChatGPT网页端制作正式AI图稿，Agent负责架构、开发、素材技术接入、Blender建模和验证。

最终流程：

```text
启动 → 3D沙漠探索世界（可直接选文化主题）
        ├─ 纹彩院：发现藻井、主动抬头 → patterns文化导览 → 选玩法 → 选关 → 游戏/结果
        ├─ 乐舞馆：听到乐声、主动唤醒飞天 → music主题
        └─ 洞窟：主动观看九色鹿长卷 → stories主题
```

- 三个目的地独立探索，没有强制线性通关、体力或前置解锁。起点附近纹彩院、较远乐舞馆、最远崖壁洞窟；距离用真实步行时间验收，不能挤成小广场，也不能大量空走。
- 洞窟内部按用户概念图陈设；第257窟只作为九色鹿故事依据，不照搬它的内部陈设，也不宣称3D是原窟复原。
- 所有二楼只展示，不可进入；乐舞馆二楼是开放乐廊与乐师，不能退回旧封闭格窗。
- 靠近文化区域只提示，玩家主动确认才切镜头/演出；可暂停、跳过、退出，最后自主进入主题或继续漫游。
- 原2D为视口内独立屏幕，不是向下滚动长网页。教学正文、小考和拼图碎片区允许内部滚动。
- 每次进入主题先教学，顶部醒目“直接玩游戏”；学习参与记录与通关分开。不要恢复“完成首关才解锁”的限制。
- 只显示核心文字。不能重新加入冗长导语、宣传句、逐条找不同分析；文化来源集中在教学、资料和结果主体。
- 纹样主题只有找不同、拼图、填色；music/stories内容没做完就明确筹备中，不能造假课、假关卡。
- 新3D手机只横屏；原2D保留横竖屏适配。自动化模拟不等于真实手机验收。
