# 莫高窟 v008 独立样片验收

独立预览： http://localhost:4215/?view=entrance#/ 。沿台阶、甬道进入大佛殿；佛前可用右下角“抬头 / 低头 / 平视”和左右转向按钮。外部 v007 和此前原始资产保留，没有覆盖正式地图入口。

## 实际空间与造型

- 用户佛像整体（含原有背光）等比缩放为35米，宽23.5424米、深17.7349米；人物沿用1.8米。主室宽28米、深25米，佛像前缘距离内室入口约6.27米，两侧最窄包围盒间隙各约2.23米。
- 真实四坡覆斗顶：四个平面向上收拢，顶部4×4米小平面放藻井，净高39.2米；主要侧壁24.2米，前壁20.45米。斜面继续铺千佛。没有在下方另放平顶。
- 窟顶中心按现有山体剖面和佛像背光位置确定；逐顶点检查佛像至斜顶的竖向余量，最低约2.22米。新版山体仅切出所需内腔，外形、九层楼和入口轴线保留。
- 九色鹿、沙弥故事带均高4.1米，下沿0.7米；各自完整画卷连续绕过门墙和侧墙转角。九色鹿前端位于回望入口时的右半门墙；沙弥尾端位于左半门墙。深处剩余墙面和故事带以上铺千佛，故事带以下铺横向装饰。
- 千佛按源图完整行裁出重复单元，接缝放在底地和行间；不镜像、不叠化人物。两段L形故事画共享连续的原图UV区间。沙弥纸白边未进入壁面，原图及坐标换算均归档。
- 洞外看入保持近黑，进入后按摄像机位置和时间逐渐适应，内部仍保持昏暗。仅调整洞内材质，不改变室外曝光；壁画没有自发光。这是游戏明暗适应处理，不是物理光传输模拟。
- 当墙体或佛像迫使镜头贴近人物时，暂时隐藏人物，避免后脑挡满画面；退出近距离后恢复。没有修改人物GLB或动画。

## 故事与交互

沙弥共用原九色鹿播放器：导语独立播放，随后五段依次定位、放大、完整段落字幕和旁白、退回全卷。五张高清局部图按原比例显示，第三张竖幅保留完整画面。全部控制仍在字幕框之外；支持暂停、重播、空格跳过、退出和结束后选择。正式配音尚未交付，本版使用本机 Grandpa 中文临时旁白，可按配置替换导语、五段和结束七个音频文件。

九色鹿五段及第三段双图逻辑保持。两个故事按钮分别在对应L形壁画附近触发，中央通道不叠加提示。故事播放期间冻结角色和环境声，退出恢复原位置。
