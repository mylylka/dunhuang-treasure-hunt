# 环境样片 v002：区域地表、岩脚接地与驼队轮廓

本轮按2026-11-03用户批注修订独立 Blender 样片，不修改正式世界、行动线或已认可的可行走缓坡。太阳沿用西北315°、高度30°。v001原样保留，渲染与贴图在`outputs/environment-study/v002/`，源工程在`art-source/world/models/environment-study/v002/`。

## v001问题与修改原则

### 沙砾和戈壁

旧版在每个4米贴图块里无条件均匀随机放置780／3800个石子，独立几何石子又用另一套均匀随机分布。两类地面主要相差数量，既没有干净的砂面窗口，也没有形成硬土区、沉积带与碎石聚集区。增加分辨率不能修复这个问题。

新版拆成三个空间尺度：

- 大尺度：独立的世界坐标区域分布，控制哪里裸砂、哪里硬土、哪里容易积聚碎石。不将这些区域塞进短周期细节贴图，不按规则圆形盖章或直线划块。
- 中尺度：砂土沉积、风蚀磨平痕与土质差异。用温暖而克制的色差、粗糙度和极浅法线表现，不靠大凹凸或暗灰斑代替。
- 小尺度：细砂与部分埋入的砾石纹理。独立石块只保留少量，和材质共用宏观疏密规则；小尺度细节单独变化。

沙砾以安静的暖砂面为主体，砾石只在少数片状或带状区域聚集；近看才读到轮廓。戈壁另设浅硬土、磨平表面与扁片碎屑层，仍有少石与几乎无石的砂土区；与沙砾的区别不能只是石子更多、颜色更暗。地面整体保持平缓。

底色中不画死太阳阴影。微材质和世界区域遮罩分开保存；此次世界遮罩是独立研究区域，接入整幅游戏前需要按世界范围重新生成或分块烘焙，并实现对应的材质混合。单独把一张微贴图重复铺满地图并不能复现这套分布。

### 巨石接地

旧版整个岩脚使用中心点的一次地形高度。岩体底部跨越几十米，当坡面向下变化时，外缘便离开地面。阴影强度、AO或者统一下移一点都不是根本修复。

新版按完整岩脚范围查询实际地形三角网格，底缘与低层外扩处均需检查，保留厚实体结构并在沙面下收口。岩脚与坡面连续衔接，不以悬空薄裙或单独方形基座盖缝。小碎石在最终旋转、缩放后复核接地与埋入。

### 驼队构图

旧版虽然把骆驼沿沙脊排好了，但没有检查相机方向的背景：七只中五只与背景岩体轮廓重叠，颜色相近导致难以辨认。

新版保留七只、真实大小与远景距离，改到以天空衬托头颈、驼峰和身体的沙脊。主机位及相邻地面机位共同检查；牵绳锚点随骆驼朝向变换，支撑足与坡面接触，步态抬脚保留。独立样片的机位检查不冒充正式路线验收，接入世界时仍需复核实际玩家路线。

## 本轮查看方式

两种地面使用相同的远、中、近机位：远景看区域色块与开阔感，中景看沉积和疏密，近景看细砾与埋入。图库同时提供岩群原机位修正版、岩脚近景，以及主／相邻机位的远方驼队。

验收围绕这些图和相应几何采样、贴图颜色空间及局部重复检查进行。不跑2D玩法测试、全项目回归或无关地形穷举。实际采样参数、图片尺寸及检查结果分别保存在本版本manifest与`work/world/`，以生成结果为准。
