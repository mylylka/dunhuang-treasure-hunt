# 第二馆二楼几何浮雕

按确认示意，在乐器后厅的琵琶侧墙和吹奏乐后墙各设置三个等距浅浮雕框，使用阶梯转角、双线与上下菱形；墙面为浅米色，墙裙为低饱和石绿，顶部为深赭红几何檐带。西墙饰面延续至前廊边缘，保留露台开口及原有乐器摆位。

天花采用浅暖色顶面及中央几何浅浮雕，保留原楼梯、碰撞和采光。装饰使用合并的静态几何，进入楼梯或二楼时按需加载，不增加图片请求；不参与射线拾取，接入既有室内光照。

电脑和模拟手机横屏从院门实走至二楼，检查了楼梯、露台及琵琶、笛子、羯鼓点选。首屏检查未请求二楼浮雕模块。类型检查通过，墙饰、天花、光照和乐器定向测试共 17 项通过。截图和记录存于 `work/world/music-upper-relief-v001/`；模拟手机并非实体手机实测。
