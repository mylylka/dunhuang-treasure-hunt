# 填色闪金／闪银实施方案（已批准）

2026-11-04。婧婧已明确回复“实施”，批准本方案。当前按以下范围开发；验证结果另行登记，不预记为已完成。

## 玩家看到的变化

- 在现有电脑色盘、手机常用色盘及可拖动完整色盘加入“闪金”“闪银”，色块直接显示颗粒和明暗质感。手机常用区保持3×2六格，采用青绿、赭红、白、墨黑、闪金、闪银；其余纯色仍在完整色盘。完整色盘将12纯色、金银和自由选色统一排列为四列，不增高挤压画布。保留至少44px触点，不增加说明弹窗。
- 操作仍为选色块后点封闭区域。保留原线条与区域边界，金属箔纹固定在原图坐标上；缩放、移动、屏幕方向变化不重新铺纹。
- 首版为静态细碎箔纹和固定亮暗反光，不增加循环闪烁或粒子动画。使用可复现、缓存的程序材质采样，不增加大图下载，不改线稿、区域蒙版或参考图。

## 作品与操作

- 底色与金／银材质共同参与撤销、擦除、清空、自动保存和主动提交。纯色覆盖会移除该区域的金属材质；至少填一个有效区域即可提交。
- 游玩、完成预览和原尺寸PNG导出共用材质渲染，刷新后纹理不随机变化。现有柔和填色过渡及减少动效设置继续生效。
- 旧作品存储原文只读保留；新增材质作品写独立的新版本本地记录。按关卡及线稿版本优先读新记录，缺失才读旧记录；已清空的新记录不能让旧画复活。
- 不更改线稿版本、通关记录、账号或数据库；不做数据库迁移，不删除旧文件或旧作品。

## 改动和验收范围

改动限定为填色材质模型、状态规则、渲染、作品保存/导出、现有色盘入口及相应类型通信。继续使用当前静态试玩服务，完成后构建更新。
