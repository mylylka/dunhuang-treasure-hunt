# 莫高窟整山体量修整 v002

用户指出v001正面棱线近乎垂直、上下岩层折线对齐。原因是各层共用同一组截面拐点。此版保留v001，分别设计下部支撑岩层、上部岩体起脚轮廓和顶部轮廓，顶点数量、位置与倾斜方向均独立，棱线在岩台处结束或横向错位。只修整体体量，不扩展地图或开展整山烘焙。

## 目录与边界

沿用v001结构，新建`art-source/world/models/mogao-massing/v002/`、`public/assets/world/mogao-massing/v002/`、`outputs/mogao-massing/v002/`，对应脚本与网页采用v002后缀；局部构造轮廓定义放`scripts/mogao-massing-profiles-v002.py`。过程截图与验证位于`work/world/mogao-massing-v002-*`，不删除或覆盖v001。

保留六组主要岩体、连续主体、约58米的最高点、45米九层楼及1.8米人物尺度。新模型在Blender中做独立上下层体块后进行几何合并，使用固定的轮廓点，不添加随机噪声。对照截图采用与v001相同的正面/斜侧机位。

验收重点是棱线错位与斜向转折、岩台局部收束，以及侧面厚度；程序检查通过不等于美术通过。正式地图与碰撞、九色鹿故事、旧资源均不改。
