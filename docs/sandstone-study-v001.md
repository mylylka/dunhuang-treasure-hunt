## 制作与检查

1. 主体使用明确设计的非对称轮廓、断面和岩台；固定的局部切削位置，避免统一高度带贯通整块、等距裂缝和大面积重复三角面。微表面程序纹理只负责颗粒与浅风化，不决定主体外形。
2. 低模保留轮廓、断面、深裂隙和岩台厚度。高模增加浅剥蚀与表面起伏；独立UV展开，高模向低模烘焙颜色、切线空间法线、AO和粗糙度。光照方向不烘焙进颜色。
3. 网页仅加载GLB/PBR贴图；使用现有游戏的灯光颜色、强度、ACES曝光。提供正面、斜侧面、侧面、近景、1.8米人物第三人称尺度参照，材质/素模切换；不通过雾或额外后处理掩盖造型。
4. 检查贴图确实进入GLB、UV范围和面积、网格面数、文件大小、各视角效果与网页加载错误。视觉验收由用户决定。

## 实际制作方法与复现

- 轮廓、岩台厚度、层间退让、两条主要裂隙及五处局部缺口使用固定控制点与布尔切削。没有把参考原图当作模型贴图。
- 在这个独立资产上以3厘米体素清理交叠倒角和细长退化面，保留清理前的构造网格；不是对莫高窟整山应用重网格。高模源与减面后的低模均保留。
- UV沿主要朝向分缝，使用角度展开并重新排布；不将细小斜面直接投影为零宽纹理条。低模UV单独用于烘焙与GLB。
- 固定的厘米级表面扰动和颗粒材质只负责浅风化。没有随机改变主体尺寸、岩层高度或裂缝位置。原始大体块仍是人工指定控制点构成，这版并非艺术家逐笔雕刻成品。
- 颜色不烘焙阳光；法线采用切线空间，AO与粗糙度/金属度打包为ORM。导出为一个材质批次。Blender源工程打包贴图，独立保留高模、低模及构造参考。
- 网页入口`http://localhost:4209/`：正面、斜侧、侧面、近景、第三人称；支持鼠标旋转、缩放及素模/表面细节切换。此页复用游戏光照和色彩管理参数，但没有接入或改变正式地图，也不是可行走的关卡。

复现顺序：Blender运行`scripts/build-world-sandstone-study-v001.py -- --stage shape --skip-renders`，随后运行同脚本`--stage bake`；再运行`node scripts/build-sandstone-study-v001.mjs`和`node scripts/serve-sandstone-study-v001.mjs`。Blender命令使用`--python-exit-code 1`。

检查脚本：`scripts/audit-sandstone-study-v001.py`读取Blender工程，检查网格闭合、UV覆盖和颜色烘焙缺失；`scripts/verify-sandstone-study-v001.mjs`检查GLB纹理/UV/切线、受保护资产SHA、网页五个视角与操作、1.8米人物及小横屏布局。

## 尺度核对

用户指定九层楼约45米、人物1.8米，目标高度比为25:1。当前v006楼顶世界高72米、平台高6.85546875米，平台以上约65.145米；人物原资产标称2.017米，未达目标。本样片中仅把人物实例等比缩放到1.8米，保留人物原GLB。整山接入阶段应将楼体本身从平台面到最高点校准为45米，台基高度另记，并同步处理外部入口、楼体宽深与碰撞，不以拉远镜头代替尺度校准。
