# 绘世厅连续演绎与收藏方案

## 入厅与故事

首次进绘世厅，沿用 B 厅的非阻塞提示，逐字显示用户给出的三句总览，接「请点击壁画欣赏故事」。点墙上任一壁画或题名即可开场，提示随之收起。

九色鹿目前会按旁白连续推进，镜头依次展开全图、用金框定位、推近局部，再退回全图。绘世厅的《五百强盗成佛图》和《火宅喻》改用同一流程。两部目前有供稿文本，没有录音，首版按分句字幕自动推进。每张局部图持续到这段字幕读完，较长段落按自然停顿拆成短句，让手机屏幕能读完。保留暂停、继续和退出。结语在全图上播完后，可选「再看一次」或「继续漫游」。本轮统一绘世厅的两部连续故事，九色鹿和沙弥沿用现有旁白推进，B 厅单件展品沿用现有展签。

## 观佛口与奖励

- 独立记录《五百强盗成佛图》和《火宅喻》两个完成项。每部以结语播完为准。提前退出不记完成，反复观看同一部只计一次。
- 未完成时，绘世厅的观佛口采用 B 厅同款金光。金光和人物、镜头碰撞共用门洞位置和状态。恢复站位或直达平台也核对锁定状态。B 厅的十二件展品与自身门禁继续独立计算。
- 两部看完并回到漫游后，金光淡去，人物和镜头可通过观佛口。第一次开放时显示「绘世厅观赏完成，观佛口已开启」，在屏幕中心授予《绘世观壁笺》。B 厅首次开放时同样居中授予《敦煌观展手卷》。奖励图环绕动态金光，点击可直接展开，也可收下后继续探索。减弱动态效果时使用静态金光。

## 《绘世观壁笺》与右上角收藏

《绘世观壁笺》用展开的牛皮纸版式。卷首放绘世厅总览，再说明敦煌壁画如何在不同画面里讲故事。两幅各有出处、时代、全图、分场看点和讲解。《五百强盗成佛图》沿用原稿七段，《火宅喻》沿用两段。重用供稿图文，正文为可滚动文本，缩略图进入阅读视口后加载。

主游戏 3D 右上角增设「我的图鉴」，与探索位置无关，打开后暂停漫游。列表显示已获得的牛皮纸奖励，先接入 A 厅《绘世观壁笺》和 B 厅《敦煌观展手卷》。既有 B 厅完成记录直接识别，已领取的奖励可在这里重读。第一馆的探索手记、填色作品库与游戏入口仍按各自用途呈现。图鉴读取同一试玩地址下的浏览器存档。

## 验收

- 首次入厅与从楼梯返回验证提示触发。两部故事在桌面及手机横屏能自动播至结语，复核暂停、提前退出、字幕可读和原位恢复。
- 初次及只完成一部时实走到金光处，验证人物和镜头阻挡。两部完成后实走上台，复核直接进入、刷新恢复和一次性完成提示。
- 从两个展厅及主游戏打开收藏，验证新旧存档资格、手卷可读及返回原位。比较首屏与打开收藏后的请求，核对跨馆资源和阅读插图按需加载。
