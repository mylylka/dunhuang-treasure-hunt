# 3D探索世界：灰模试玩

> 2026-10-31：用户已明确验收本阶段。本文保留灰模历史记录；当前交付见[美术样片v001](3d-world-art-sample.md)。

本阶段在 `codex/3d-world` 开发。对应批准计划的第一道验收：确认空间通路、镜头与交互，再进入正式美术样片。当前并非完整3D功能交付。

## 已实现

- `#/`：真实Three.js灰模，沙漠道路、院门、工作台、一层开放藻井厅、不可进入的二层体量。远方乐舞馆与山崖仅预留体量。
- WASD/方向键行走、Shift跑步；Q/E或鼠标右拖有限转镜头。手机横屏显示摇杆，幅度控制走跑。
- 角色防穿墙、墙边滑动、行走范围、台阶坡道、独立镜头遮挡检测。
- 藻井范围内只出现“抬头看看”，主动触发后切观察镜头；可暂停、继续漫游或进入原纹样导览。
- 通过教学进入2D后卸载Three.js；返回时恢复厅前安全点，不自动重开互动。原Phaser生命周期独立。
- 院内右侧设故事测试点，可预览完整长卷与两段局部。背景冻结、虚化；暂停、重播、上/下一段、退出。无正式旁白时用明确标记的字幕预览，读完后手动推进。
- `#/themes`保留直接选择主题。无WebGL2、运行器加载失败及外层懒加载失败均保留备用入口。
- 后台、失焦或手机转竖屏停住输入；回到横屏后需主动继续。减少动效同时读取游戏设置与系统偏好。

## 试玩方式

开发：`npm run dev -- --port 4186`，访问 `http://localhost:4186/#/`。

构建：`npm run build`。静态预览：`node scripts/serve-preview.mjs --no-open`。端口4186同一时间只运行一种服务。

1. 沿浅色道路前行，左转穿过院门。
2. 走到庭院尽头、一层厅堂中央，点击“抬头看看”或按F。
3. 选择“了解藻井的秘密”进入已有教学；顶部“探索”可返回3D，原玩法仍从教学中的“直接玩游戏”进入。
4. 在院内右侧深色展板附近点击“试看九色鹿故事”；这只是播放器技术验证，洞窟演出还未制作。
5. “暂停”中可回到起点。探索位置只保留在当前标签页会话；刷新可恢复，关闭标签页后不保证保留。

## 代码边界

| 文件 | 职责 |
| --- | --- |
| `src/app/WorldScreen.tsx` | HUD、触屏摇杆、暂停、入口与挂载/卸载 |
| `src/app/WorldBoundary.tsx` | 最外层3D懒加载失败的备用入口 |
| `src/app/WorldStoryPlayer.tsx` | 图片、字幕与可选音频的统一控制 |
| `src/world/runtime.ts` | Three.js绘制、调度、视图切换与释放 |
| `src/world/geometry.ts` | 本阶段程序灰模；正式模型阶段替换 |
| `src/world/road.ts` | 道路中心与完整路宽，场景、路线图和通路验收共用 |
| `src/world/layout.ts`、`src/world/scenery.ts` | 行走范围、镜头距离与沙丘/边界石/岩柱完整尺寸；渲染和碰撞共用 |
| `src/world/movement.ts` | 纯移动/碰撞/坡道规则与安全位置 |
| `src/world/camera.ts` | 跟随、遮挡、藻井观察预设 |
| `src/world/input.ts` | 键盘与鼠标输入，禁用时清空 |
| `src/world/events.ts` | 必须主动开启的共享事件状态 |
| `src/world/session.ts` | 独立会话记录与旧/坏记录保留 |
| `src/content/world/` | 独立资源URL与故事内容 |

独立键为 `dunhuang:world-session:v1`（sessionStorage），只保存位置、角色方向、相机偏转、已访问事件。坏记录写回前备份；存储不可用时提示重试，当前内存仍可游玩。原游戏、作品、学习和声音键保持不变。

灰模无GLB、正式人物绑定、飞天动画、音乐和六段完整旁白。本阶段不建立假的music/stories课程，也未进行GitHub推送或公开部署。下一阶段使用Blender制作正式纹彩院和小旅人样片，素材规范见 `world-asset-contract.md`。

## 验证记录

检查包含内容校验、TypeScript、规则/存档测试、世界桌面与手机模拟、原玩法回归、生产子路径资源与渲染生命周期。截图及测量放 `work/world/`。浏览器模拟性能仅作为本机基线，不等于2021年以来真实手机的30帧验收。

2026-10-31验证结果：

- `npm run build`通过内容校验、类型检查与生产构建；`npm run test`共197项通过。
- 原2D功能在桌面/手机Chromium共108项通过；世界单独在桌面Chromium、手机模拟与WebKit共18项通过。暂停一帧延迟和Safari遮罩焦点问题修复后，世界18项已全部复验。
- `npm run test:production`通过原教学、找不同、填色、拼图的实际生产构建与横竖屏检查。
- `node scripts/verify-world-production.mjs`通过真实网址子目录、触摸摇杆、连续三次往返释放、Three与Phaser不并行绘制、外层脚本加载失败回退等检查。
- 本机自动化Chromium基线：页面导航至可操作约899ms，首屏资源传输4,393,802字节；179次帧间隔采样中位数/P95均约16.7ms。这是本机灰模基线，不代表正式模型性能或真实手机成绩；尚未完成真机持续运行验收。
- 生产构建位于`outputs/web`；测试截图与指标位于`work/world/production-*.png`及`production-report.json`。构建保留旧输出，不自动删除历史文件；本轮未推送或部署。

需要用户确认的第一阶段重点：行走速度与距离、角色屏占比、院门和厅堂是否方便进入、抬头镜头是否完整、从教学回世界的操作是否顺畅。颜色、人物细节与纹样贴图属于下一阶段正式美术验收。
