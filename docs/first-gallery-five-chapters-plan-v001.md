### 台词、人物转向和镜头

给每句带观察意图的台词登记对象与动作。例如把“墙上这些图案”和“旁边这些实物”拆成两个节拍。小旅人先看向当前对象，再出对应字幕或开口。有配音后按句或关键词时标接动作，静音时字幕仍带同样的动作节奏。常驻操作按钮和画外音只承担信息提示。

| 台词提到 | 小旅人看向 |
| --- | --- |
| 「这面墙上的图案……」 | 转向大厅后墙，头部看当前有线索的壁画区域。 |
| 「旁边这些实物……」 | 从墙面转向右侧桌案，目光落到桌面。台词若点名物件，就看那朵莲花、鸟摆件或葡萄。辨物题用“桌上这些东西”引导，避免提前把答案指出来。 |
| 「最上面的小方格……」 | 身体朝藻井井心的地面投影，头颈抬起。人物几乎正站井心下方时保留身体朝向，避免左右晃。镜头抬到能看清井心，玩家再主动打开高清图。 |
| 「怎么一点颜色都没有？」／「旁边还有颜料呢」 | 先看画架线稿，再低头看颜料桌。下一句说“试试”或作品挂回时，视线回到画板。 |

现用人物 `traveler-tripo/v002` 有独立头颈骨骼和 2.25 秒的 `HallLookUp`。入厅抬头曾在独立样片验收，第一馆新机位仍需试演。藻井采用自然抬头幅度，目标过陡或姿势不合时由镜头补足。桌案和画架使用可对准实物的短动作，身体只做必要的转向，头颈微调高度。运行时以基础动画当帧姿势为起点再叠加限幅的视线，避免与走跑动画抢骨骼或逐帧叠加扭转。

人物在近处停稳后才安排较大的身体转向。走动、跑步或玩家接管镜头时立即放开控制，离开触发区后取消过期动作。常规转身只改变表演姿态，脚下位置与玩家镜头保持独立。目标被柱墙遮挡时等到合适站位，或保留字幕提示。验收时从正侧面检查“朝向是否跟台词换对了”，另测走动中断、跳过、无声字幕和手机触控。[已有抬头动作的验收记录](character-cinematics-v001-acceptance.md)

## 2. 借物补画

- 进厅后先看到墙，走到能辨认局部轮廓的位置出现一句自言自语。靠近桌案时显示本轮提示，鼠标和触屏可点桌上实物。F 打开同样的三个物件选择，方便玩家用键盘逐项选，不用猜准镜头准星。
- 每轮先辨物，再完成一次小操作。顺序为莲花选最后一片花瓣、飞鸟辨方向、葡萄选接得上的藤蔓。各轮反馈独立，选错只提示观察依据。可退出当前局部操作，已完成的轮次仍在墙上。
- 选对实物后，从其模型锚点飞一束短促纹光到墙面，再打开同图坐标的小操作。点对后单次写入本轮进度，局部恢复随即显示。三轮均提交后，整墙过渡到完整图并记壁画印记。刷新时直接按已完成轮次恢复画面。重玩只使用临时残损图，离开即恢复永久墙面。
- 现有桌案 GLB 在引擎中是合并的纹理网格。三件实物需要独立拾取代理，以精确模型位置记录在装置局部坐标内。点击射线先检查遮挡，墙、柱和桌面不能把背后物件误判为命中。先量代理和手柄热区，再决定是否需要按物件拆出可发光的网格。复用当前桌案，不增加素绢台和拼图台。
- 已找到 [完整图](/Users/liujing/Downloads/藻井馆新背景墙-完整.png)（2168×725）与 [脱落图](/Users/liujing/Downloads/藻井馆新背景墙-脱落版.png)（2170×725）。目检有同一套边框、中心莲花、两侧飞鸟和葡萄。初步比对的 29 个有效匹配点能支持整体微调，三个主要修补区受剥落影响，尚不能用自动匹配证明局部对齐。用完整图坐标校正脱落图后逐区闪切检查，再把两张图挂在同一 UV 展示面上。
- 仍缺三张经确认的分区蒙版、补全候选及定稿的提示坐标。建议先出一张对位复核图，明确用中心莲花、上方其中一只鸟、下侧其中一串葡萄做三个操作点。具体边界以原图对位为准。候选从母图分层或裁切制作，核对正确项唯一。最终动画沿用原图边饰，游戏手记注明这是玩法化复原。

## 3. 藻井寻秘

- 复用实际井心图。运行用的 767×766 JPG 与已归档的《三兔飞天藻井_中心部分.jpg》哈希一致。原比例展示，可放大。正式画面需以这张图的方向描热区。
- 在同一套归一化坐标里登记 3 个兔身、3 只实际耳朵及各自的归属。第一只兔子任选，先找它的两耳，再引导点相邻兔与它共用的一耳，最后点第三只验证。点过的耳朵不会重复计数。高亮用精确轮廓，手机实际点击区可以适当放宽，重叠边界以当前步骤和最近目标判定。按钮选择和图片点击走同一套规则。
- 三级提示逐步增加信息。完成时写入一次印记和一条观察手记。后续能自由观察或重玩。保留入场相机朝向、俯仰和位置，退出时恢复。R、右键和手机镜头动作只抬头，第二次主动确认才进入高清图。
- 复用现有纹样课程的第 407 窟来源登记和图注作为手记素材。文化旁白的文本、图像与出处分开登记。

## 4. 画架设色和作品库

- 唯一推荐首关为 **《飞天持莲》 `coloring-feitian-lotus`**。稿件提到的四关是早期清单，当前纹样主题已登记五个填色关卡。《飞天持莲》线稿和院内画架都是云纹、持莲手与画面右侧垂带的同一构图。运行 GLB 里的图已烘进整组纹理，首版应先测画面平面边界及透视，接独立画面节点，用原关卡线稿替换面图并做角点对位。四个旧关适合留作后续创作选择。
- 复用 `ColoringScreen`、调色工具、区域图、材质、撤销及原作品合成器。3D 通过外层路由传入入口令牌及返回点。填色期间不加载 3D 语音或教学。首次限定本关时，上一关、下一关入口不跨到其他关，返回键和浏览器后退均回院内。
- 点击「完成作品」后，先保存当前真实颜色和材质，再记录展品与设色印记。成功后回**院内原画架**，短暂停留并换画，随后自动恢复控制。稿件第四章有“返回大厅原画架位置”的说法，现物已安装在院里，建议返回实际装置前。画架完成时如果玩家本来就在院内，解锁资格照常写入，仪式可等他靠近左侧画卷台，无需先折返大厅。
- 普通 2D 提交仍走正常结果页，只新增一张收藏快照。画架仅在从画架完成或玩家主动选画时换图。未提交退出保留草稿。保存失败继续停在填色页，保留当前颜色供重试。
- 收藏按 `artworkId` 存独立版本、关卡 ID、线稿版本、颜色、闪金闪银等材质和提交时间。支持同一张线稿收藏多个配色；编辑旧画时另存或明确覆盖选中的收藏。展出记录另存 `displayedArtworkId`。合成用原尺寸区域图，展示只在 Canvas 副本轻暖化，缩略图按需生成。贴图上传限制分辨率，换画释放旧纹理。线稿版本不兼容时展示提示并保留原作记录。

## 5. 权限、保存和技术落地

- **永久状态与临时会话。** 当前 `dunhuang:progress:v1`、`dunhuang:learning:v1` 保存原玩法和教学，`dunhuang:artworks:v2` 保存每关每线稿版本的最新颜色和材质，不能同时收藏同版本多幅。地形位置、镜头与旧事件访问存在 `sessionStorage`。拟新增单独的版本化本地存档，存三个事件进度、仪式是否展示、独立作品以及选中展品。旧作品按同版本且已提交的记录只读导入，使用可去重的来源 ID，不产生新印记。旧草稿继续读取。
- **提交一致性。** 三印记齐全与解锁资格在一次写入完成；解锁资格从真实完成事件推导，演出状态独立。作品、展出 ID 和画架印记也一起提交，避免刷新时出现先解锁后丢画。每次提交带稳定请求 ID，重试不重复建收藏。损坏原记录备份、存储失败提示和重试沿用项目约定。异标签读取最新状态，允许并行编辑时在实现阶段明确写入冲突策略。
- **首访权限。** 新剧情入口首访只开放第一馆。三事件后立即开放纹样主题小游戏及第二馆 3D 入口。第三馆及后两馆的 2D 游戏待本馆规则。用同一访问判断覆盖主题、玩法、关卡、结果页、直接输入 URL 和相邻关导航。在综合地图验收可从正路和坡地绕入的所有边界；已有旧测试入口、单馆预览及旧存档保持独立。
- **入口冲突。** 现行默认世界一直提供「直接选主题」，而五章稿提出首访锁定。建议先在新剧情预览落实门禁并显示解锁条件，再决定何时替换默认入口。WebGL 或资源确实失败时提供独立「兼容游玩」入口，允许进入纹样主题的 2D 内容，兼容入口的完成不自动生成 3D 印记。普通门禁和设备故障分别验收。
- **画架来源。** 外层导航保存本标签页的受限尝试令牌、固定关卡、版本及校验过的返回站位，允许该页刷新恢复。直接链接不能凭查询参数伪造来源。普通 2D 的返回、结果页、老关卡存档和相邻关行为沿用现有流程。Phaser 与 Three.js 轮流挂载，关闭、失败、返回时释放场景资源。
- **互斥和语音。** 复用 `WorldScreen`、世界运行器、遮挡拾取、字幕和短语音播放的生命周期。三个事件用单一前台占用状态。借物补画和三兔观察期间冻结移动，轻提示期间允许行走。现有角色语音有第二馆“哪里来的音乐声”“好美的飞天啊”等，并非第一馆定稿台词。第一馆的角色短句、三轮画外音、总结和画架成功反馈待配音。原型先用字幕，录音交付后再替换。保留跳过、减少动效、后台、失焦与横屏规则。

### 素材怎么交

- **图已有。** 先用现有完整壁画、脱落版、井心图和《飞天持莲》线稿。三个修补区的蒙版、候选裁片、三兔点击范围、道具点击范围和小旅人注视点都由开发侧从原图与模型制作、量取。现阶段的用户素材缺口是定稿后的角色与旁白录音，试玩可先用字幕。
- **壁画位置。** 建议以观看者的方向为准，默认选①中心莲花、②左上飞鸟、③右下葡萄藤。如果要换，在完整壁画的未裁切副本上圈出三个目标并标号，另外保留一份干净原图。圈选只表达要修哪朵、哪只或哪一串，蒙版边缘由开发侧描。若沿用默认，也可以直接用文字说明。
- **人物看向哪里。** 在试玩截图里圈出物件，写一句「说‘旁边还有颜料’时看画架右边的小颜料碗」即可。相似的物件尽量圈具体一个。也可以写「先看画稿，再看笔筒」。开发侧将圈注对应到模型上的真实位置，随装置移动和旋转。
- **仅在现有脱落版对位验收失败时补图。** 用完整壁画作编辑底图，脱落图只作质感参考。提示词见下，交付未裁切 PNG。若编辑结果仍让完整边框或主体位置漂移，继续用原图做分区修补，不用另一张新构图凑成一对。

> 以我上传的《藻井馆新背景墙-完整.png》为唯一编辑底图，保持 2168×725、全幅平视构图和四周边框。严格保留中心莲花、左右飞鸟、葡萄藤及边饰的位置、大小、方向和轮廓。仅在我圈出的中心莲花、左上飞鸟、右下葡萄藤及紧邻的小片墙皮做不规则掉色与浅层剥落，露出暖赭色旧灰泥，保留部分花瓣、鸟和藤蔓轮廓供辨认。剥落大小错落，参考第二张脱落图的质感。其它区域尽量保持原像素。输出未裁切的全幅 PNG，不改比例、不镜像、不添加物件、透视、文字或水印。
