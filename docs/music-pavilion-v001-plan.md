# 乐舞馆独立样片 v001 制作约定

2026-11-01：用户批准“纹彩院到乐舞馆的可玩路线＋乐舞馆首版样片”，并要求开始。沿用项目目录约定，不修改 AGENTS.md。此文先登记本轮范围和验证标准。

## 本轮交付

- 在独立预览串联已有小旅人、A树、已确认灌木、Blender沙丘、石板路及两段人物镜头；旧预览和正式入口保留。
- 乐舞馆保留既定地图位置及参考中的左侧开放二楼乐廊、右侧飞天壁画、前庭和入口关系。Blender建模，保存源工程，导出区域GLB；二楼只展示，不开放行走。
- 从纹彩院原门出发，经同一世界中的石板支路走到乐舞馆；不重排其他建筑，不制作洞窟和新地形变体。
- 靠近壁画只出现提示；主动按F/按钮后停止移动并聚焦壁画，灰转彩，仅两处自由飘带末端微动。原母图人物、双手、琵琶保持静止；补底仅采用局部，记录像素范围。提供暂停、重播和退出，退出恢复当前安全位置，不自动重开。
- 本轮无正式乐声和旁白文件，采用文字观察提示，交付明确登记音频缺口；不伪称古乐复原，不虚构已完成的music教学或小游戏。

## 验证标准

保护旧GLB、Blender工程、AGENTS及已有美术原稿哈希。检查模型正面/侧面/斜侧、第三人称接近、前庭和完整壁画；原图完整比例，零姿态分层重组及静止区域像素一致。实际走通纹彩院到馆前，检查道路全宽、人物碰撞和镜头遮挡；主动互动、暂停/重播/退出、刷新恢复、2D往返、失焦/后台/横竖屏、减少动效、失败重试及默认入口回归。浏览器检查串行，提供真实截图与交互录像；真机性能不以模拟结果替代。
