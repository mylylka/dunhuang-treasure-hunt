# 三馆步行连通方案

## 现状

第一馆的综合试玩已经有第一馆通往乐舞坊的步行路线。完成第一馆三项探索后，乐舞坊的实体区域放行。该入口目前载入的是早期乐舞坊场景。第二馆双层试玩和第三馆展陈试玩分别使用独立的场景加载范围、室内行走面和位置存档。沿地形路径采样检查，从乐舞坊院门经月牙泉一侧到九层楼外台阶约 151 米，各段可步行。第二馆单馆目前走到该处时还没有加载九层楼和展陈。

## 接入

1. 以现有第一馆综合入口为入口，沿用地图上的院门、石板路、岔路及九层楼台阶。玩家自行走完全程，地图继续只标示位置。按靠近范围补载当前第二馆双层场景和第三馆展陈。
2. 沿用第一馆三项探索开放第二馆的规则。以第二馆已记录的九个飞天年代、十二件乐器与一次历史服饰换装，作为游戏世界与第三馆路线的共同解锁条件。第三馆从正路与坡地接近时执行同一门禁。保留旧进度和已领取图鉴。
3. 依当前站位切换地形、第二馆和第三馆的行走面与镜头规则。跨院门或九层楼正门时保留同一坐标与朝向。小导游跟随边界及各馆独立试玩、恢复站位和小游戏返回点沿用现行规则。综合入口单独保存路线位置。
4. 完成路线后恢复第二馆图鉴领取后的第三馆解锁通知，复用第一馆通知样式和院内游戏入口提示。通知关闭后继续原地漫游。

## 验收

- 用新档从第一馆出发，依次验证第二馆与第三馆锁定、解锁、沿正路步行入馆及从坡地绕行时的门禁。复核旧达标档可直接步行入馆。
- 在电脑和模拟手机横屏实走院门、山路、九层楼外台阶、正门及两层展厅，检查资源是否按靠近范围加载、是否有穿墙或站位跳变。
- 在院外路段和各馆楼层刷新，核对原位继续。检查从各馆小游戏回到原入口，复核三份单馆试玩的独立存档。
