# 手机横屏主画面与手势改版

2026-11-03，依据用户真实手机截图和后续双指缩放、滑动选关要求实施。最初的布局评审页保留在`work/mobile-play-redesign-v001.html`，正式实现使用现有素材和玩法配置。

## 当前行为

- 找不同、拼图、填色采用高度优先的大主图、浅纸色背景和右侧紧凑操作栏。手机支持横屏，扣除浏览器实际工具栏与安全区域后重新适配，不要求隐藏浏览器界面。首关3:2和新关1:1均保留真实比例，1×完整显示。
- 找不同两侧只保存一份`ImageView`（1～3倍连续倍率、原图归一化中心）。任意侧双指开合、移动中点及单指拖动都同步影响两侧；只在松手后确认为轻点时找差异，放大后的命中使用同一原图变换。B仍只在已确认差异区域局部露出，画面与标记按观察窗裁切。详细提示可移动到目标，窗口变化和竖屏中断保留视图与发现。后续用户确认直接缩放已足够，已移除该玩法独立观察入口，旧组件文件保留。
- 填色保留1×、2×、3×按钮，同时支持1～3倍连续双指开合与放大后单指平移。双指、拖动、取消、后台及模态弹窗期间的触点不能上色；非模态色盘打开时可在露出的画布继续着色。小参考始终同屏且可放大；常用6色直接显示，完整色盘保留12色和自由选色。右侧采用简洁纵向操作栏，返回只显示原箭头图标并保留无障碍名称；清空重涂、撤销与主动提交直接可达，不使用说明型更多菜单。
- 拼图主板按高度放大，碎片托盘在旁连续纵向滚动。拼片使用原有互补曲线，点击或拖放规则不变，高清画布中的拖放、滚动和目标采用CSS逻辑坐标。
- 五种游玩主页面常驻同字体同颜色、无装饰底图的纯文字“上一关”“下一关”。只链接同主题同玩法的实际相邻关；缺少相邻关时保留disabled且无href的按钮，不在游玩页改成返回目录。找物准备页不显示这些功能，开始后显示。仅结果页以下一关为首要操作，末关或单关返回目录。相邻关切换不记完成，填色自动保存不等于提交。
- 电脑填色主线稿支持鼠标滚轮连续缩放：向上放大、向下缩小，范围仍为1～3倍；在允许的画面边界内保留鼠标指向的原图位置。倍率按钮和双指缩放共用同一视图。滚轮监听仅由填色选择启用，不改变找物的长卷滚动；模态、阻挡和销毁时不操作画布，滚轮不会着色、增加撤销历史或滚动整页。
- 拼图原图/重来与填色清空均在主面板直接操作；说明型“更多操作/填色操作”窗口取消。保留真实图像观察、文化资料、暂停与错误反馈。2D装饰弹窗外层透明，原彩边及内容面保留，关闭统一44px线条SVG；触屏关闭不显示蓝方框，键盘保留暖色圆形焦点。
- 选关取消分页，所有实际关卡和筹备位共用一个原生纵向滚动列表。手机缩小封面并按宽度显示3～4列，低高度可直接滑到最后一行；标题和返回固定。电脑宽窗仍可同时看六卡。正式关的封面、标题、按钮可键盘进入；筹备位不产生入口或记录。

## 技术约定

`src/runtime/image-gestures.ts`集中处理原生Pointer Events、捕获、双指比例、中点和轻点/拖动区分。`image-view.ts`提供同源变换和边界约束；`render-coordinates.ts`分离Phaser物理画布和CSS逻辑坐标。所有玩法画布DPR上限2，找不同HTML标签不随画布栅格化；填色显示纹理按CSS显示尺寸乘实际画布DPR生成，最多保留原图像素，不AI补画。

仅找物仍计时，其数量、时限和素材抽样未调整。存档格式、正式关卡ID和3D方向策略不变。竖屏继续使用统一提示和`setBlocked`生命周期，同局恢复，不销毁重开。

短音效仍采用原温润木石WAV与默认40%，尊重原静音/音量偏好。已修复触屏仅在pointerdown解锁和旧pending resume锁住新手势两处问题；触屏抬起/点击同步解锁，每个新主动手势可重试恢复，旧反馈停止或过期不补播。真实API、挂起恢复与非零波形专项只证明浏览器侧链路，不代表iPhone扬声器已实测；细节与证据见[本轮流程记录](level-flow-and-floating-palette-v001.md#移动音效诊断)。
