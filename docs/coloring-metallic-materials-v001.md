# 填色静态金银材质 v001

2026-11-04，按用户明确批准的[实施方案](coloring-metallic-materials-plan-v001.md)开发。仅新增静态闪金／闪银，不变更原线稿、区域ID图、参考图、关卡作品版本或通关规则。

## 渲染与操作

`src/games/coloring/materials.ts`定义`sparkle-gold-v001`、`sparkle-silver-v001`的程序箔纹。材质在原图像素坐标查找256×256缓存纹理；第一次选择/预览生成，之后复用，不请求额外大图。Voronoi碎箔、折痕和固定细亮片只表达静态质感，不做循环闪烁、粒子或每帧噪声。已交付的材质ID和采样配方应保持稳定，后续视觉升级另加版本，不能让旧作品随刷新改样。

底色与`RegionMaterials`并存，材质选择用固定底色与带版本ID；原生自由颜色输入保留上次纯色色值。纯色覆盖、擦除、清空和撤销共同处理两份映射，同RGB换材质也是编辑，重复同一材质不新增历史。金银沿用约200ms过渡，减少动效时立即显示目标纹理。

`render.ts`为游玩、结果和PNG共同生成原尺寸画布，金银与普通色均只写选中区域像素，再复合原线稿。过渡仅为本次变化区域缓存两端RGB并混合，不在每帧重建箔纹。视窗缩放、拖动及方向变化只调整显示，纹理不重铺。重新加载运行器时同步当前工具，避免色块选中金银而画出默认纯色。

## 本地作品兼容

- `dunhuang:artworks:v1`只读保留原始字符串；新编辑只写`dunhuang:artworks:v2`，不运行数据库迁移。
- v2按关卡ID及原`artworkVersion`存`colors`、`materials`、更新时间和可选提交时间。缺少新版本条目才回退旧条目，有效空v2条目遮住旧画，清空后不会复活。
- 旧记录只在内存补空材质；未知/孤立材质不作为有效着色。保存失败提示并允许重试，坏v2原文备份失败则拒绝覆盖，旧v1原文不改。
- 仍至少真实填一个有效区域才能提交。普通编辑不伪更新提交时间，不改旧progress、学习或音效偏好。

## 色盘

电脑原12纯色后追加金银；手机保持原3×2六个常用槽，按各关标签选择青绿类、赭红、白色、墨黑、闪金、闪银。其余纯色仍在完整色盘。完整浮窗将12纯色、2材质和自由选色排成四列，保留44px触点、拖动、关闭与初始不遮挡画布规则；不新增说明弹窗。
