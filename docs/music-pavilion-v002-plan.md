## 实际根因

1. 飘带：`music-pavilion.ts` 的上、下自由端位移上限分别仅原图2.2、1.8像素，网页壁画缩小后约1像素；前1.8秒没有飘动，之后才渐入。此前像素变化检查只能证明发生了变化，不能证明肉眼可辨。
2. 路线：现馆体中心在 `(18,-3)`，纹彩院中心约 `(-12,-11)`；两段短支路没有形成视线遮挡与转折。即使延长道路，若保持开阔视线，仍会一出门就看见馆舍。
3. 围墙：现前庭墙高仅0.9米，约为纹彩院院墙的三分之一，无法形成高墙围院的空间。
4. 跟随镜头：移动改变角色 heading，cameraYaw 只响应手动镜头操作；因此人物朝侧面走时，镜头仍保留原方向。不能直接让cameraYaw每帧追heading再反过来影响移动，否则持续按侧向键会绕圈。
5. 壁画：`awakened` 同时承担已观看记录和画面颜色，退出后的颜色由它保持为1，重载又从 visitedEvents 恢复彩色。
6. 乐师：廊面顶约4.56米，坐凳基准4.57米；下层屋顶的屋脊约4.95米，并覆盖乐师所在的z位置。屋面穿进坐凳和袍脚，遮住廊面，形成坐在瓦顶上的效果。
7. 布帘：顶部设在3.55米，而檐下彩梁下缘约3.72米；前后深度也不一致，没有吊杆或挂接构件。

## 建议的整改效果

### 到达乐舞馆：约35—45秒正常步行

以跨出纹彩院院门为起点，按当前正常步行1.8米/秒设计约63—81米的有效路线，不通过降低速度凑时间。只向独立样片外侧延展这条支路与乐舞馆区域，其他建筑不移动。

顺序：离开院门 → 第一段石板曲径 → 沙丘坡肩与植被遮挡馆舍 → 转弯前先听到微弱乐声 → 第二个弯口露出高墙、门口与屋顶 → 入院看到乐廊和壁画。

- 以两次自然转折组织路线，中段已有Blender沙丘的坡肩承担主要遮挡，植被辅助；不用透明度或距离开关让建筑突然出现，不靠雾掩盖。
- 目标为前半段看不见馆体，转弯前听到乐声，正常步行再过约5—8秒开始见到馆舍。声区按空间距离设置，不用倒计时强制触发；跑步、停留、折返行为保持自然。
- 新馆前庭墙体初设2.8—3.2米高，保持砂色墙面、压顶与明确院门；完整路宽与人物净空通过门洞，避免窄门/高墙造成镜头钻墙。
- 新区域范围、道路、树木实例、沙丘完整网格、人物碰撞及相机活动范围一并配置；不修改全局正式地图边界来迁就样片。
- 不改变已确认的不规则铺石板设计，不用散碎石路替代。

### 飘带与壁画状态

- 仍仅活动两处自由末端，连接处固定；让弯曲沿末端逐渐增强，两条飘带节奏略错开，避免整幅平移或统一抖动。
- 在1279×925真实观察视角中，以末端约6—10屏幕像素的单侧幅度作为初始试调目标，依据实录调整。先复核蒙版与补底覆盖，再提高幅度；不把扩大数值等同验收。
- 彩色出现时便能察觉飘动，变彩结束后持续，暂停立即冻结。减少动效设置仍受尊重。
- 每次进入观察都从灰色开始；每次退出、提前退出、切去主题或重新加载后，探索中的壁画都是静态灰色。观看记录只记体验完成，不再决定墙面颜色。重播仍从灰色开始。
- 原母图人物、双手、琵琶与其余纹样固定，不重绘全图；补底不够用时列出所需局部素材，不将接缝或残影当成可接受结果。

### 行走镜头

- 持续转向行走时，镜头约0.8—1.2秒平缓转到人物后侧；短暂侧移不过度转动，停止后不自动反复回摆。
- 连续一次方向输入保持其世界移动方向，不因镜头自身转动而让角色兜圈；重新输入方向才按当前视角解释。
- Q/E及鼠标右拖优先，手动观察后留短暂保持时间；手机摇杆采用相同原则。演出、弹层、暂停时不自动转向。
- 新自动跟随仅在v002预览启用，保留已通过的角色关键节点演出和旧预览操作。

### 乐廊与布帘

- 在Blender中调整下层屋顶为廊面前方的檐棚结构，使平整木廊地板、前缘与栏杆清楚可见；乐师及坐凳放到栏杆内侧、真实廊面上，核对脚/凳/地板/瓦面不相交。
- 布帘顶部连到实际檐下横梁/吊杆，增加必要挂接；顶部与杆的位置共同配置，保持下缘人物头部净空。
- 用正面、侧面、斜侧面与玩家近景检查，不仅凭正面效果判定空间正确。

## 乐声素材缺口

现项目及已知下载素材目录未找到乐舞馆长音频，只有原游戏短提示音。不能把短提示音循环当作乐舞馆音乐。

可选择：用户给出一段本地琵琶/笛声音乐路径；或先制作明确标注待替换的原创短拨弦乐句，仅验证远近衰减与先闻声后见馆的节奏，不声称真实乐器录音或古乐复原。

长音频独立通道，遵从现有静音/音量与浏览器主动手势解锁；随距离渐入渐出，后台、离开世界和暂停时停止/暂停。缺音频时保持可操作并明确该验收项尚未完成。
