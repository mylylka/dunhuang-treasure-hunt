- 保持当前区域的正面规模：山体约120米宽，顶部主要在60—68米之间。采用厚重、连成整体的砂岩台地，少量宽大斜切面、直立断面及两三处横向退台；设计轮廓和切面，不堆叠大量石块、不使用随机尖峰。
- 中央山顶略收低，九层楼顶部略高于其后崖线。九层楼底部宽约34米、总高度约65—70米；这是游戏构图尺寸，不宣称历史建筑测绘复原。
- 依参考图采用贴崖的层叠楼阁正立面：朱红柱梁、灰绿屋瓦、浅砂色楼身；檐口逐层收分，上层更紧凑，顶层保留明显翘角与顶部轮廓。用重复构件保持梁柱、栏杆笔直；先做清楚的九层比例和轮廓，不加入大量微小雕饰。
