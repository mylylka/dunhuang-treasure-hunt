## 保留的产品与内容边界

教学仍为：首页主题 → 七屏文化导览（可跳过） → 三种玩法 → 分玩法关卡 → 游玩与结果。每次从首页进入主题都先展示教学，顶部可直接玩，不以教学或首关完成阻止游玩。七屏19个图例均有独立放大观察，知识小考6题不伪称掌握知识。学习资料与真实文物图源沿用此前登记，不用本轮AI补线冒充文物修复。

手机检查使用触屏模拟，真实手机Wi-Fi体验仍需用户试玩。完成表示参与活动，不代表知识掌握。AI教学示意不等于原壁画、原貌复原或历史颜料鉴定。
