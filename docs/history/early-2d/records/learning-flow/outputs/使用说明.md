# 敦煌寻宝记 · v0.1 AI 美术试玩版

## 怎样打开

双击同目录的 **启动敦煌寻宝记.command**，它会启动本地预览并打开浏览器。保留终端窗口即可持续游玩，结束时关闭该窗口或按 Control+C。

固定试玩地址：**http://localhost:4186**。

手机需要与电脑连接同一 Wi-Fi，在手机浏览器输入启动窗口中显示的局域网地址。手机是否能够连接还取决于本机网络和防火墙设置。浏览器触屏模拟已验证；实际手机仍请试玩确认。

## 现在可以玩什么

- 首页展示三个主题：纹样与色彩；飞天、乐舞与服饰；壁画故事与宗教文化。
- 首页仅选择主题，不提供直接跳入首关的快捷入口。返回箭头与上级名称都可点击。
- “纹样与色彩”限定找不同、拼图、填色；当前可玩仍为找不同首关。完整教学导览和独立玩法选择页正在设计，尚未加入当前版本。
- 「纹样与色彩」的找不同入门关可完整游玩。其余主题提供介绍，明确标记内容制作中。
- 两幅图任意一侧都可以点击。找到五处变化后自动记录完成，并显示观察解释。
- “放大观察”可在A/B之间切换，保持同一位置，选择全图或通用2倍区域。看清后返回原图标出差异，不会丢失本局进度。
- 提示与重试不限次数。重玩不会撤销已完成记录。
- 「设置」可启用减少页面和按钮动效。

首页、选关、游玩和结果分别占一屏，使用按钮切换，无需向下拉网页。游戏图、进度、提示和操作按钮同时显示；手机横竖屏切换会重新安排两幅图并保留本局已找到的位置。较长的游玩说明、学习内容和文化来源在独立文字面板中阅读。

当前主界面已去掉宣传句、重复状态与常驻小字。游玩页的“学习目标与来源”入口已移除；完成后可选择回看发现。通用说明弹窗复用现有装饰面板，无需补充装饰素材。

已接入婧婧提供的15项AI美术：两张背景、通用面板、两张按钮底图、五枚图标、三个主题封面和首关A/B图。画面属于AI教学示意，不是原壁画照片或历史原貌复原。首关五处变化分别是右上佛像组合、上方箜篌、中央琵琶、右上圆叶与左下圆饰配色。

## 记录保存在哪里

进度保存在当前设备、当前浏览器、当前网址的本地存储中。电脑和手机不自动同步；不同网址和端口的记录也分别保存。短关中途关闭会重新开始，完成记录继续保留。

如浏览器不允许保存，游戏会显示“尚未保存”及重试按钮。不会将失败显示为已经保存。损坏记录被新记录替换前，会先保留原始备份。

## 继续补充美术或更新版本

这一批原稿已经归档到项目的 art-source/，运行素材在 public/assets/。以后把新原尺寸图片统一交给开发 Agent 即可，不需要你填写点击坐标、写 JSON 或研究命令。素材名称不必强行与代码一致，由 Agent 对照素材编号整理。

请一起提供：

1. 你选定的最终图片版本。
2. 首关 A/B 图；两图同尺寸、同构图，说明计划修改的位置。
3. 原始文化参考链接及必要的使用说明。
4. 哪些图片你希望保留或进一步修改。

Agent 会检查尺寸、透明背景和手机可读性，重新标注差异，更新素材索引与文化说明，然后重新验证。代码根据素材的占位标记自动隐藏对应“待替换”徽标；按钮和面板的实际切片参数也登记在素材配置中。

## 后续开发入口

项目根目录包含源码、AGENTS.md、依赖锁文件和维护文档。程序采用 Phaser 4.2.1、React、TypeScript、Vite。正式关卡在内容目录自动发现；增加已有玩法关卡主要增加图片与配置。

开发命令：`npm run dev`。生产构建：`npm run build`。构建文件位于本目录的 `web/`。

本批实现的是公共框架与找不同首关，其他玩法将在后续批次接入。当前交付为本地试玩，尚未公开部署。
