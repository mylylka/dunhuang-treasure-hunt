# 原稿与参考资料约定

此目录保存婧婧在 ChatGPT 网页端生成并提供的正式美术原稿，以及来源、提示词和版本说明。当前没有正式原稿；游戏中的 SVG 均为 Agent 创建的技术占位素材。

## 目录与命名

新增原稿时采用以下结构，实际收到文件后再创建对应版本目录，不预先放空图文件：

- `shared/<asset-id>/v001/`：背景、面板、按钮和图标原稿。
- `themes/<theme-id>/v001/`：主题封面原稿。
- `levels/<level-id>/v001/`：关卡 A/B 原稿、制作提示词和图源说明。

版本号采用 `v001`、`v002` 递增。同一版本的原稿不覆盖、不删除；新稿建立新版本目录。文件名用英文 kebab-case，例如 `patterns-intro-a-source.png`、`patterns-intro-b-source.png`、`source-notes.md`。不要把 API 密钥、token 或账户信息放进素材说明。

## 每批原稿一起保留的信息

1. 素材 ID、用途、原始尺寸、文件格式和生成日期。
2. 参考页面链接、洞窟号、年代、壁面部位；说明照片、临摹、复原或教学重绘的性质。
3. 实际使用的提示词、生成版本，以及用户确认的修改说明。
4. 需要保持不变的构图和计划修改的局部；找不同关应明确三处差异。
5. 如有适用的使用条件、作者署名或授权说明，保留在来源记录中。

首关参考为敦煌研究院的[莫高窟第329窟](https://www.dha.ac.cn/info/1425/3577.htm)。正式游戏图应标记为“敦煌纹样启发的教学重绘”，不能把 AI 图称为原壁画照片或有证据支持的历史原貌复原。

## 原稿与运行素材分开

首关 A/B 原稿为 **1536×1024**，运行版统一为 **1200×800**；两图保持相同画幅、比例与对齐。原稿保留在本目录，处理后的文件进入 `public/assets/levels/patterns-intro/`。其他资产尺寸与透明背景规范见 [素材接入说明](../docs/art-assets.md)。

正式美术由婧婧生成和修改；Agent 负责规格与提示词、来源核对、尺寸和格式处理、差异标注、局部合成、技术整合及验证。需要内容性修图时，返回用户继续制作。
