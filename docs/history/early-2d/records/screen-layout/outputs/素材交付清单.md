# 正式美术交付清单

全部正式美术由婧婧在 ChatGPT 网页端制作。Agent 提供规格、提示词、参考资料和验收反馈，负责技术接入。

## 统一方向

敦煌矿物色＋画卷展陈；二维手绘、清楚轮廓、平涂为主，少量纸绢与矿物颜料质感。界面以浅绢、砂米为底，赭红强调，辅以石青、石绿和深褐。文化内容图以参考资料为依据，不能为统一界面而任意改写历史图像。

建议界面色板：`#F5EBD9`、`#E8D6B8`、`#934A3A`、`#2F6B73`、`#5D7C61`、`#493E34`。这是界面设计色板，不是古代颜料标准。

不需要另做第一关独特背景、角色精灵或动画表。标题、按钮文字、数字进度和点击标记由程序呈现。面板与按钮只生成空白底图，切片、排字与交互状态由 Agent 处理。

## 优先级

先确认 **A图、电脑背景、通用面板** 的风格。A图确认后再制作B图；其余图片可分批交付，不必等待15张全部完成。

## 第一关文化参考

主参考：莫高窟第329窟，初唐，主室窟顶的莲花飞天藻井。取莲花、卷草与联珠等元素作教学重绘，不声称复原文物。

- 敦煌研究院：https://www.dha.ac.cn/info/1425/3577.htm
- 数字敦煌：https://www.e-dunhuang.com/cave/10.0001/0001.0001.0329

先观察完整参考，再选择清楚局部。保留图源和相应使用说明。不要把原作不完全对称当成错误。

## A/B 图制作要点

先确认A，再在同一图上分次局部编辑。三处变化为：一片较大的叶片缺失；一个较大的花瓣轮廓变化；一段卷草朝向改变。实际位置以你最终A图为准，不沿用现在的占位坐标。

不要分两次独立文生图生成“相似图片”，也不要让AI在B图中添加圈选标记、文字或对照排版。

ChatGPT选区编辑可能影响选区外，Agent会检查。程序右图以A为底，仅覆盖B的已确认区域，避免把其他变化带入题目；覆盖块仍须检查边缘和色调。
