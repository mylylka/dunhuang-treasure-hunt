# 敦煌寻宝记 · 文化教学与游戏试玩版

## 怎样打开

双击同目录的 **启动敦煌寻宝记.command**，它会启动本地预览并打开浏览器。保留终端窗口即可持续游玩，结束时关闭该窗口或按 Control+C。

固定试玩地址：**http://localhost:4186**。

手机需要与电脑连接同一 Wi-Fi，在手机浏览器输入启动窗口中显示的局域网地址。手机是否能够连接还取决于本机网络和防火墙设置。本轮增加内容的浏览器与补线版检查结果以验收记录为准；实际手机仍请试玩确认。

## 现在可以玩什么

- 首页展示三个主题：纹样与色彩；飞天、乐舞与服饰；壁画故事与宗教文化。
- 首页仅选择主题，不提供直接跳入首关的快捷入口。返回箭头与上级名称都可点击。
- 每次从首页进入“纹样与色彩”都先显示文化导览，已看过也会显示。顶部“直接玩游戏”可随时进入游戏选择，不必先看完教学或参加小考。选中玩法后进入该玩法的关卡页。
- “纹样与色彩”只显示找不同、拼图、填色三个入口。找不同已开放藻井寻踪、莲瓣与团花、忍冬与卷草三关，每关五处差异；六关计划的后三关标记筹备中。填色已接入三兔莲花、莲花茶花、葡萄石榴、葡萄莲花四关；拼图开放莲花平棋、三兔飞天、双龙藻井三关，六个拼图位置的后三关为筹备中。三个玩法都可进入，其余两个主题仍标记未开放。
- 两幅图任意一侧都可以点击。找到该关五处变化后自动记录完成；结果页显示文化参考与简短AI图说明。
- “放大观察”可在A/B之间切换，保持同一位置，选择全图、通用2倍区域或上侧4倍细节。看清后返回原图标出差异，不会丢失本局进度。
- 提示与重试不限次数。重玩不会撤销已完成记录。
- 「设置」可启用减少页面和按钮动效。

首页、选关、游玩和结果分别占一屏，使用按钮切换，无需向下拉网页。游戏图、进度、提示和操作按钮同时显示；手机横竖屏切换会重新安排两幅图并保留本局已找到的位置。较长的游玩说明、学习内容和文化来源在独立文字面板中阅读。

填色玩法封面为横版满幅图，只在入口封面裁切，游戏和参考图完整等比。找不同的参照图A、变化图B使用清晰的HTML标签。当前主界面已去掉宣传句、重复状态与常驻小字。游玩页的“学习目标与来源”入口已移除；完成后的文化参考直接显示在结果页主体；不再展示五条差异分析。通用说明弹窗复用现有装饰面板，无需补充装饰素材。

当前素材索引登记47项，包括原15项AI游戏美术、13个教学素材ID、两关找不同4项、四关填色12项和三关拼图3项。AI类游戏画面为教学示意，不是原壁画照片或历史原貌复原；拼图使用开发者交付的参考图，完整保留原有水印，不凭文件名确认窟号、年代或原作者。首关五处变化分别是右上佛像组合、上方箜篌、中央琵琶、右上圆叶与左下圆饰配色。

## 怎样玩自由填色

选择“填色”后，可进入三兔莲花、莲花茶花、葡萄石榴或葡萄莲花。每关提供12种颜色，也可以使用“自由选色”自选颜色；选好颜色后点击线稿里的可着色区域。线稿与较小的参考配色图在同一页同时显示，参考图可以点击放大；不作为评分标准，可以创作自己的配色。

- “擦除”后点击区域，可撤去该区颜色；“撤销”回退本局上一步修改。
- “清空重涂”可一次清空当前颜色，这一步也可撤销。重新进入后不保留整段撤销历史。
- 1×看全图，2×和3×可拖动画布看细处；拖动不会当作填色点击。
- 至少着色一个有效区域后，“完成作品”才可使用；点击后主动提交，不要求填满所有细碎区域。
- 结果页展示你的颜色与原线稿叠合后的作品，可“导出PNG”。

点击着色有约200ms的柔和过渡与短促触点反馈。开启游戏“减少动效”，或设备系统启用减少动效时，立即换色并关闭这类反馈。

三兔莲花、葡萄莲花已采用本轮授权的局部补线v002，只补参考图中有依据的断口，不重描整幅，原稿和旧版本保留。三兔的三只兔身因真实共耳结构连通会一起着色，已与圆内背景隔开；葡萄莲花的外方框已闭合，纸外不参与着色，部分本来相通的飘带仍会联动。其余两张未发现同等级大断口；不承诺每个极细小空隙都能独立点击。可着色区域数为三兔345、莲花茶花511、葡萄石榴611、葡萄莲花510，这些数字不表示需要全部填满。浏览器和手机检查结果以验收记录为准。

## 怎样玩拼图

拼图目录先保留六关，前三关已有素材并开放：

- **莲花平棋**：3×3旋转拼图。图块位置不动，点击一次顺时针转90°，观察原图把九块朝向恢复正确。
- **三兔飞天**：12片不规则凹凸拼图。
- **双龙藻井**：20片不规则凹凸拼图。

碎片可以拖向拼图位置，也可以先选片、再点击目标位置。放对才吸附，放错不会计入进度；全部拼回后才完成。手机碎片区分页，使用上一组、下一组查看其他碎片，网页本身无需滚动。提示不会自动完成拼片或旋转，提示与重新开始都不限次数。

横竖屏切换会重新安排画布和碎片区，保留本局状态。离开关卡再进入会重新打乱；已完成记录不会因重玩消失。原图右下来源水印保留，程序拼片不代表文物修复。

另外三关只是筹备位置，没有可玩链接或完成标记。计划和后续素材要求见《拼图六关计划.md》。

## 怎样使用文化教学

文化教学位于独立的悬浮标签面板，明亮底色和“文化导览”标识将它与游戏区分开；不需额外制作装饰素材。七屏依次讲解：装饰部位、花叶纹样、几何纹样、动物纹样、组织方式、色彩、知识小考。可以用上方章节按钮切换，也可以按上一页、下一页顺序阅读。

每屏点击图例名称切换实物与解释。所有图都有“放大查看”：打开观察窗后，可选择全图、2倍、3倍，用鼠标或手指拖动、用方向键移动，点击复位回全图；关闭后继续教学。有局部观察区时另有“看重点”，卷草也可直接查看细节。

最后一屏明确叫“知识小考”，六题分别对应装饰部位、花叶形态、几何纹样、三兔共耳、组织方式和色彩。右侧题目区可向下滚动，整个网页不滚。六题均作答即可交卷，答错也可看解释并交卷；也可随时直接玩游戏。跳过或只答小考不会被记为已看完全部教学，导览完成只表示参与，不代表掌握所有知识。

“资料”中保留洞窟、图像与研究来源，采用现有装饰面板。教学实物照片与AI游戏图分开标注；当前显示的主图与补充图已逐图检查无叠加水印。你补充的第254窟平顶图用于平棋与忍冬教学；第254窟图和三兔拼版可在资料中点击查看。带知乎水印、出处未核的忍冬整理图暂不展示，原文件完整归档。第329窟改用吴健摄影、敦煌研究院供图的无水印照片，菱格改讲第407窟实物边带；第257窟原构图的无水印高清版仍未找到。第254窟图和三兔拼版的原始出版出处保留待补说明。完整更新与缺图清单见《教学图源更新记录.md》。

色彩部分先观察照片中的冷暖与明暗，再介绍颜料材料和检测依据，不把屏幕取色当作古代原始配方。照片显示今日影像，AI图只用于教学游戏。

## 记录保存在哪里

教学访问章节、导览完成记录与游戏完成记录分别保存在当前设备、当前浏览器、当前网址的本地存储中。已浏览章节记录继续保留，但每次从首页进入主题仍先展示导览首页。电脑和手机不自动同步；不同网址和端口的记录也分别保存。找不同或拼图中途关闭会重新开始，游戏完成记录继续保留；拼图沿用同一完成记录格式，没有新增账号或存档迁移。填色的区域颜色会另外保存，重新进入可继续创作；撤销历史只属于本局。

填色作品按关卡和画稿版本单独保存在浏览器里，不把图片塞进存档。补线或区域图升级后，旧作品仍保留，不把旧区域编号硬套到新图；如提示有旧版作品，可继续用新版创作。

如浏览器不允许保存，游戏会显示“尚未保存”及重试按钮。不会将失败显示为已经保存。损坏记录被新记录替换前，会先保留原始备份。

## 继续补充美术或更新版本

这一批原稿已经归档到项目的 art-source/，运行素材在 public/assets/。以后把新原尺寸图片统一交给开发 Agent 即可，不需要你填写点击坐标、写 JSON 或研究命令。素材名称不必强行与代码一致，由 Agent 对照素材编号整理。

请一起提供：

1. 你选定的最终图片版本。
2. 找不同需同尺寸、同构图的A/B及变化说明；填色需配色参考与线稿，并说明发现的断口；拼图需完整原图及希望的模式、片数。
3. 原始文化参考链接及必要的使用说明。
4. 哪些图片你希望保留或进一步修改。

Agent 会检查尺寸、透明背景和手机可读性，重新标注差异，更新素材索引与文化说明，然后重新验证。代码根据素材的占位标记自动隐藏对应“待替换”徽标；按钮和面板的实际切片参数也登记在素材配置中。

## 后续开发入口

项目根目录包含源码、AGENTS.md、依赖锁文件和维护文档。程序采用 Phaser 4.2.1、React、TypeScript、Vite。正式关卡在内容目录自动发现；增加已有玩法关卡主要增加图片与配置。

开发命令：`npm run dev`。生产构建：`npm run build`。构建文件位于本目录的 `web/`。

当前实现公共框架、文化导览、3关找不同、4关自由填色和3关拼图，共10个正式关卡。当前交付为本地试玩，尚未公开部署。

找不同与拼图各自的六关计划、学习焦点及后续素材要求，见同目录《纹样找不同六关计划.md》和《拼图六关计划.md》。筹备位只展示内容计划，完成素材和配置验收后才会开放；不会提前写入游戏记录。

首页标题已放大并使用朱砂色文楷字形，“选择主题”改为“开启敦煌探索”。悬浮教学框的装饰边缘与浅色内容面分开，所有操作都在内容面内，无需补充新装饰素材。
