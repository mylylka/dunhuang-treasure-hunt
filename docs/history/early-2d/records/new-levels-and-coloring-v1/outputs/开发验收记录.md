# 文化教学与分层导航 · 开发验收记录

日期：2026-10-28（北京时间）。

## 实际完成

- Phaser 4.2.1、React、TypeScript、Vite 本地项目与依赖锁文件。
- 三主题首页、文化教学、玩法选择、分玩法关卡选择、帮助、减少动效设置、结果反馈。
- 首页选主题 → 文化教学 → 选择游戏 → 该玩法关卡 → 游玩与结果，各占一屏。手机首页按钮切换封面，关卡目录根据空间展示6、3或2张卡片并分页；常规桌面同时展示六关计划，手机分页。帮助、教学正文与资料弹窗在独立文字区域内滚动。
- 纹样与色彩七屏文化导览、19个图例面板、独立悬浮教学面板与七个页签、全图与局部观察、热点与最终六题知识小考。每次从首页进入主题都先显示导览，随时可直接玩；交小考只要求作答六题，实际全章访问才记导览完成，跳过不伪记完成。
- 找不同入门关：依据可用宽高选择并排或上下排布，完整等比显示；任一侧点击、无限分级提示、重开和局部合成。手机横竖屏切换保留本局状态。
- 独立的localStorage教学记录与原游戏完成记录、失败重试、损坏数据备份保护。取消找不同首关通关前置，不改旧游戏存档结构。
- 用户交付的15项AI美术全部接入；v001原稿与运行PNG分开保存，原稿尺寸、透明通道和SHA-256登记完整。旧几何SVG保留但不再引用。
- 首关五处差异与对应提示、讲解、点击区域；运行B图采用A底加物象蒙版，仅保留五个配置区域内的目标修改。
- 通用“放大观察”：A/B切换、全图与五个2倍区域、返回继续本局，手机无需滚动网页。
- 自动发现关卡 JSON、配置与素材文件校验、独立测试关注入。
- 界面清理：主界面装饰性碎文案、首页首关直达与游玩页学习来源入口移除；纹样主题限定三类玩法；返回图标可点击/键盘操作；主题封面透明3:2容器；弹窗复用U03面板。
- 素材索引登记28项（15项AI美术、13项教学资源，含保留的旧来源）；用户第254窟平顶图用于平棋与忍冬，三兔拼版补充展示，带水印的忍冬整理图退出展示并保留原档。来源、水印和未核实信息保留，不用AI补画伪造实物细节。
- 首页图片与文字作为紧凑整体，三幅同尺寸、标题跟随图片。按钮正文独立居中，移除“再次观察”旁参与居中计算的方向符号。

三个玩法入口中，找不同已实现；拼图和填色明确未开放。其他两个主题未开放，不把入口或预览当成玩法已完成。

## 验证结果

- `npm run validate:content`：通过，3主题、1正式关卡、28项素材、0占位素材、1本教学导览7章。
- `npm run typecheck`：通过。
- `npm run test`：89项通过，含教学配置、路由和学习存储。
- `npm run test:e2e`：本轮66项用例覆盖均已通过，包含桌面Chrome、手机触屏模拟Chrome、WebKit。首次60项通过；3项并行负载时的加载超时在未改代码、未放宽阈值的串行复验中通过。横屏资料补图和WebKit全图观察的真实边界适配已修正，相关用例定向复验均通过。完整可见性阈值保持0.999。
- `npm run build`：通过，生产构建在 `outputs/web/`。
- `npm run test:production`：通过，检查实际构建的背景、面板与按钮图片请求，以及各屏幕无页面滚动、图片与操作区完整在视口内、1440→360→844横竖屏切换、点击及刷新保存。

浏览器检查包括：重复点击不重复计数、提示后完成、重开归零、退出重进、刷新保存、写入失败后重试、图片加载失败后重试、结果页不能伪造完成。隔离两目标测试使用不同关卡ID，且B测试图故意整幅为洋红色；实际截图像素确认只有两个配置区域出现B，其余区域继续显示A。测试关没有进入正式内容目录或实际玩家记录。

屏幕布局检查包括360×640小竖屏、844×390横屏、说明教学资料弹窗的内部滚动与关闭，以及注入6个真实测试关与5个筹备位后的分页和全部可玩入口可达。测试同时检查图片、提示和按钮的位置，避免只隐藏页面溢出导致内容被裁掉。

针对用户截图中的1279×925视口，三张首页实际图框均为381×254，图像到标题间距均14px；关卡按钮正文与底图的水平、垂直中心偏差均不超过1px。教学七屏、游戏选择、关卡页和补充图资料弹窗均验证控件在视口内；截图等待HTML图、SVG图、CSS蒙皮及本地标题字体解码后输出。

素材像素核对：五个区域内均有实际变化，区域外变化像素为0。九宫格按新面板和按钮重新配置；五枚图标、按钮、面板均为真实透明通道。放大器检查包括A/B保持选区、2倍背景位置变化、返回后进度保持与继续通关。

## 验证范围

手机使用浏览器触屏模拟，实际手机Wi-Fi访问和触控体验仍需用户试玩确认。AI图不等于原壁画或文物复原。教学参考敦煌研究院、数字敦煌、研究院供图的新华社图像及中国科学院材料研究；用户忍冬整理图未核实具体窟号、年代和原出版出处，已退出展示、保留归档；另外两张补图仍待补原出版信息。第257窟同构图无水印高清图仍缺，教学已采用第254窟与第407窟可核验图例。更新与缺图在《教学图源更新记录.md》中列明。拼图、填色及其他基础玩法尚未实现。

## 本轮用户反馈落实

- 七屏教学使用独立悬浮面板，复用U03装饰、明亮底色和阴影；不需要新装饰图。
- 结果页五段差异分析及弹窗入口移除；文化参考进入页面主体，AI美术署名为开发者。
- 找不同目录呈现六关规划，首关开放、五关筹备。筹备位没有链接、操作按钮或完成标记，不生成正式关卡和存档。
- 第329窟总图/井心替换无叠加水印的机构供图；忍冬改用第254窟，菱格使用第407窟。可见9张主图与2张补充图逐图核对无叠加水印；未擦水印、未AI补画，旧文件完整保留。

## 首页与教学体验修订

- 首页大号朱砂色“敦煌寻宝记”，使用本地文楷标题子集，约3KB；“开启敦煌探索”替换原“选择主题”。三图等尺寸和图文间距保留。
- 外层装饰与内层浅色内容面分离，新增实际安全区几何检查；所有教学固定控件与页签都在浅色区内，窄屏短页签本身不换行。
- 每次进主题先显示导览，顶部“直接玩游戏”始终可用；跳过与完整参与分开，不使用教学完成记录阻止游玩。
- 删除所有逐页导语，19图卡标题明确显示自身部位或纹样名；边饰不再使用抽象功能句代替名称。
- 全部19图卡统一放大查看，卷草可看重点；观察窗支持缩放、移动、复位、关闭与焦点恢复，源图片不变。
- 末页为六题知识小考，覆盖前六屏，题目区内部滚动，答错也可交卷，不保存或伪造掌握分数。

边界修正：短横屏资料补图按可用窗口缩放；全图观察按真实CSS像素测量，并在内描边内留1px余量，避免WebKit对clientHeight取整造成亚像素裁剪。缩放后的局部观察允许图片超出舞台，舞台与操作控件保持在安全区内。
