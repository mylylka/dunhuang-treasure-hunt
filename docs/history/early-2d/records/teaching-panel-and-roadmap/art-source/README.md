## 目录与命名

- `shared/<asset-id>/v001/`：背景、面板、按钮和图标原稿。
- `themes/<theme-id>/v001/`：主题封面原稿。
- `levels/<level-id>/v001/`：关卡 A/B 原稿及相关说明。
- `references/<theme-id>/v001/`：教学参考原件及 `source-notes.json`。本批主题目录为 `references/patterns/v001/`，保留来源文件名，包括用户原名，不覆盖原始文字或水印。

文件名采用英文 kebab-case，例如 `patterns-intro-a-source.png`。版本号从 `v001` 递增；同一版本的原稿不覆盖、不删除，新稿建立新版本目录。不要把密钥、token 或账户信息放入素材记录。

## 每批应保留的信息

1. 素材 ID、用途、原始尺寸、格式、交付日期和校验值。
2. 已提供的参考链接、洞窟号、年代、壁面部位及使用说明；不将未确认的信息当作来源事实。
3. 用户实际提供的提示词和版本说明；没有交付的内容标记未提供。
4. 找不同关卡计划比较的目标及实际核对结果；原稿可能有全图漂移，不能据此宣称只有配置数量的差异。
5. 若提供作者署名、使用条件或授权说明，一并保存。

## 原稿与运行素材分开

本批 L01/L02 与 T01/T02/T03 原稿均为1536×1024，运行版为1200×800。共享素材按索引尺寸导出到 `public/assets/shared/`，封面进入 `public/assets/themes/`，首关进入 `public/assets/levels/patterns-intro/`。原稿完整保留。

`python3 scripts/import-art-v001.py` 使用已有 Pillow 读取原稿并导出 PNG。脚本会核对已有原稿的校验值，拒绝覆盖内容不同的 v001 原稿；交付路径不可用时可从项目归档重新导出。正常游戏运行与 `npm` 开发构建不依赖 Python。

运行版 B 以 A 为底，只在五个配置区域内通过物象蒙版合入 L02，区域之外像素与 A 完全一致。此处理用于排除原稿的其他重绘漂移，不生成或重新绘制内容。具体蒙版、九宫格与尺寸约定见 [素材接入说明](../docs/art-assets.md)。
