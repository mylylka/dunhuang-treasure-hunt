- **“莫高窟第254号窟平顶.png”**：作为平棋主展示，不能写成第257窟。平棋结构、莲花与忍冬类型与数字敦煌第254窟说明及官方公开预览对照相符；用户文件的原图片出版出处仍待补，不标称它就是数字敦煌下载原图。
- **“忍冬纹.jpg”**：完整保留图片上的文字与知乎署名水印。它是纹样整理图，不是已定位到某窟的实物照片；图中自带“北周”文字不等于年代已被核实。它只作补充观察，不用于窟号或年代判断；正式忍冬教学依据第257窟官方实物资料。

## 原稿、透明背景与文字

- 原稿不覆盖、不删除；新交付建立下一版本目录。运行素材与原稿分开保存。
- 面板、按钮与五枚图标均有真实 alpha 通道。按钮的透明留白裁切范围记录在交付清单的 `trimBox` 中。
- 标题、按钮名称、提示、数字进度和差异标记由程序显示；不将文字烘焙到美术图中。
- 素材为 AI 教学美术，不是原壁画照片或历史原貌复原。具体乐器、佛像组合和游戏配色不能直接作为文物考据依据。

## 面板与按钮的九宫格

九宫格让四角保持形状、四边沿单方向伸展、中心填充，避免整张底图被压扁。当前运行 PNG 的切片值按 `top / right / bottom / left` 记录如下：

| 素材 | 切片像素 | 对应切线 |
|---|---|---|
| 面板1024×1024 | 310 / 318 / 310 / 318 | x=318、706；y=310、714 |
| 主按钮1024×256 | 64 / 220 / 64 / 220 | x=220、804；y=64、192 |
| 次按钮1024×256 | 64 / 220 / 64 / 220 | x=220、804；y=64、192 |

实际值登记在素材索引的 `slice` 中，界面读取配置。以后替换图片时重新核对切线，不沿用不适合新稿的数值。背景、图标、封面和关卡内容图不使用九宫格；关卡内容完整等比显示。

### B 的局部合成

L01 与 L02 原稿存在全图重绘漂移，**不能说两张原稿只差五处**。运行版 B 按以下方式导出：

1. 以规范化后的 L01 为底，保留全图构图。
2. 只在五个配置区域内合入 L02 的目标内容；矩形是点击范围，不意味着整块矩形都替换。
3. 右上大像区域内部羽化10px；箜篌、琵琶和圆叶使用物象多边形蒙版、边缘模糊1.6px；六个圆饰圆心使用局部圆形蒙版、边缘模糊0.6px。上述像素均指1200×800运行图。
4. 五个区域之外的运行版 B 像素与 A 完全一致，避免将全图细节漂移混入题目。运行时继续使用 A 为底、仅覆盖配置区域的保护机制。
5. 检查蒙版边缘、目标完整性、提示、手机放大观察和点击位置。整个流程只做技术合成，不生成或重画美术内容。

## 重复导出与后续替换

`python3 scripts/import-art-v001.py` 可使用已有 Pillow 重复导出本批 PNG。脚本优先核对交付原稿；交付文件不在原位置时使用项目归档。已有 v001 原稿若内容不同，脚本会拒绝覆盖，需创建新版本。正常 `npm` 开发、运行和构建不需要 Python。

`python3 scripts/import-pattern-lesson-references.py` 负责12项教学参考的归档、PNG导出与索引登记。它保持原尺寸，遇到内容不同的已归档原件会拒绝覆盖；新的原图或资料版本须另建版本。替换教学图时同时复核面板图注、知识来源、局部观察坐标和清晰度，不能只换一个同名文件。

下一批素材先归档到对应 `v002/`，再使用带新版本名的运行文件。保持素材 ID 不变，更新路径、真实尺寸、版本与来源说明；A/B更换时同时重新核对差异区域、蒙版、提示和讲解。完成后按 `AGENTS.md` 运行内容校验、类型检查、规则与浏览器验证、生产构建，并在手机上检查细小目标可读性。公开发布仍须另行确认。
