# 地形样片 v012：绿洲搬移与双峰驼队

预览：`http://localhost:4225/`。构建 `node scripts/build-terrain-v012.mjs`，启动 `node scripts/serve-terrain-v012.mjs`。旧 v011 构建保留。

## 布局

第二馆（乐舞坊）基准从 `(185, 2.5, 15)` 移到 `(210, 2.5, -43)`，朝向从 −12° 改为 +28°。月牙泉岸线使用同一个平移及40°旋转，保留尺寸、水位、曲率和馆湖间距。建筑、庭院树木、家具、碰撞、观察镜头和文化事件使用同一地区变换。

第一馆坡顶保留，两段道路接回新门口。第一馆到第二馆约138.6米（搬移前89.8米）；第二馆到九层楼约150.6米（搬移前193.2米）。路径长度变化来自本次指定位置。音乐可听范围随新位置调整，保留出第一馆后微弱听见、下坡渐强、入院完整的效果。

## 驼队

新增三队共19只双峰骆驼，分别6、6、7只，沿北侧两条沙脊及南侧曲线沙脊排列。原七只单峰骆驼保留。新素材为内置image_gen生成的透明背景侧身双峰骆驼，采用固定竖直透明剪影，不随相机转向；底部依真实沙坡高度贴地，参与同一固定太阳的静态阴影。

- 原始生成图及提示词：`art-source/world/bactrian-caravan/v001/`。
- 运行PNG：`public/assets/world/bactrian-caravan/v001/bactrian-camel.png`（1536×1024，约2.07 MB，原字节复制）。
- 布局：`src/content/world/bactrian-caravans-v001.ts`。
- 单只高度2.52～2.91米。使用实际alpha范围设置UV，alphaTest为0.5。该表现用于远景氛围，不是可近距离绕看的立体动物。

## 砂岩与光照

只替换九层楼原山体的砂岩材质，采用外围岩群同一暖灰褐砂岩色谱，加入连续低对比沉积层理。保留山体几何、九层楼、洞窟及原侵蚀法线。太阳仍为方位250°、高度30°，静态阴影在加载阶段准备好。
