# 温润木石音效

开发者于2026年10月29日确认试听A「温润木石」。正式文件位于 `public/assets/shared/audio/warm-v001/`，七个WAV与试听原件逐字节一致；该目录的 `manifest.json` 记录时长、SHA-256及来源。合成配方和测量保留于 `art-source/audio/sfx-audition/v001/`，生成脚本为 `scripts/generate-sound-audition.py`。声音为原创程序合成，不是真实乐器录音或敦煌古乐复原。

`src/services/sound.ts` 提供一个公共播放器。首次主动手势调用 `unlock()`，实际操作调用 `play(cue)`，页面隐藏时调用 `stop()`；模块导入不会创建音频上下文或自动播放。所有声音共用一个声道，切换以12毫秒淡出收尾后再启动下一声；快速重复限频，成功与提示不被普通按钮截断，完成音最高优先。异步资源若过期、静音、切到后台或被较新动作替换，将不补发。

播放器不依赖Phaser。场景只发送类型明确的反馈，公共运行宿主转交；加载、刷新结果和无实际操作保持安静。声音加载/解码或浏览器权限失败时继续游戏，后续操作可以重试。

`src/services/sound-settings.ts` 使用独立键 `dunhuang:sound-settings:v1` 保存开关与0到1之间的音量，默认开启40%。它不修改关卡、教学或填色作品记录。读取失败使用默认值并返回警告；保存前先保留无法识别的原记录，备份失败不覆盖，保存失败由设置页显示重试。
