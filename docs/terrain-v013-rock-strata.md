# 九层楼山体横向岩层 v013

用户指出外围雅丹岩柱具有真实的横向凹凸，而九层楼山体仍是大块平面。本次在原有连续山体上雕出不等间距、不同深浅的风蚀凹层，保留已确认的整体体量。

- 使用 Blender 修改几何，水平切片改善岩层轮廓的采样；形变后的法线根据原大岩面与实际凹层共同计算，避免显露旧网格的三角对角线。
- 九道主要层位约在山体自身高度 5.6、10.3、15.8、21.9、27.0、32.8、39.4、45.1、51.6 米处。它们有轻微不规则变化，实际尺寸及网格数量见导出登记。
- 山体中央宽 32 米、底部及全部垂直坐标受保护；楼体、洞口、洞室、台阶保持原位。使用现有固定 250° 方位、30° 高度的太阳照明。
- 新模型沿用统一的砂岩材质色系，旧模型与历史预览保留。

## 文件与重建

- Blender：`art-source/world/models/mogao-strata/v001/mogao-strata.blend`
- 运行模型：`public/assets/world/mogao-strata/v001/mountain.glb`
- 尺寸、原文件哈希及几何报告：同源目录的 `export-manifest.json`
- 构建：`/Applications/Blender.app/Contents/MacOS/Blender -b -t 4 --python-exit-code 1 --python scripts/build-world-mogao-strata-v001.py`
- 网页构建：`node scripts/build-terrain-v013.mjs`
- 本地预览：`node scripts/serve-terrain-v013.mjs`，端口 4226。

网页只在启用环境版本的当前地形预览中加载新模型。静态阴影在模型加载完成后生成，因此投影包含真实岩层凹凸。
