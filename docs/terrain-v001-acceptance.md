# 连续地形空间样片 v001

2026-11-02。用户已明确授权实施；本轮仅接管3D漫游。地形、建筑位置与朝向可在独立预览验收，旧版本与原模型保留。此版本是空间样片，地表纹理、湿岸和植被疏密仍属后续细化，不将简洁沙地称为最终美术。

## 试玩

- 电脑：http://localhost:4222/
- 同一Wi-Fi手机：http://192.168.1.116:4222/（横屏）
- 独立静水材质小样：http://localhost:4221/
- 右上角“高空总览”查看全局，“返回地面”回到原人物位置。WASD/方向键行走，Shift跑步，Q/E转向，R/T抬头低头，C恢复平视；手机使用摇杆与屏幕按钮。
- 初次从纹彩院内出发，刷新恢复本样片的位置。需要从起点重看可用 `http://localhost:4222/?view=start#/`；参数使用一次即消费，避免每次刷新强制回起点。
- 构建：`node scripts/build-terrain-v001.mjs`；启动：`node scripts/serve-terrain-v001.mjs`。输出目录 `outputs/terrain/v001/`，服务为本地/局域网预览，未公开部署。

## 已落实的空间关系

| 位置 | 高程与朝向 |
| --- | --- |
| 纹彩院 | 半山腰基面26米，向+24°错转 |
| 坡顶 | 约40米，比院落高约14米 |
| 月牙谷地 | 湖面0米；乐舞坊基面2.5米，向-12°错转 |
| 九层楼与崖体 | 按红圈移到右前方，根坐标(330,10,90)，转向-160°，正面朝箭头指向的左后方谷地 |

两院门向相差36°，不再平行排列。九层楼、崖体、入口台阶、洞内陈设与触发区域整体搬迁；原6.855米内外高差保留，建筑未重做或缩小。

两段自然弯曲石板路分别约267.28米、230.29米，总长约497.57米。主路最陡短段约14.37°，顺坡连到真实门口。完整路宽通过通行采样，不依靠穿墙或悬空路面连通。

院门与院内到乐舞坊屋顶的视线由连续沙坡遮挡，采样有约13～14米余量；不使用距离隐藏开关。走近坡缘、翻坡与下行会自然展开视野。角色脚高、道路、局部平地、湖岸与镜头防穿地共用高度规则。远丘只承担背景，不扩展成可攀爬群山。

月牙湖保留用户修订后的舒展弧度和饱满中段，按水样1.75倍落入谷地，长约119米、中段宽约31.5米；使用加深的蓝绿色、浅岸过渡、缓慢细波与实时场景反射。湖岸不开放游泳，通行边界与可见岸线共源。波纹与反射为程序材质，没有重绘建筑或角色。
