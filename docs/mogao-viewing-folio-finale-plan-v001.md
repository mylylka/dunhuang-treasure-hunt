# 第三馆观佛通路、配音与游戏入口

## 两处观佛洞与一楼楼梯口

现行 A、B 厅的门洞净宽为 2.00 米、净高为 3.10 米。两个洞壁开口和连接板偏向一边，挑台又往同一侧偏了一次，且旧门框与通道侧板叠在一起。现行直行测试能在门槛或挑台前被挡住。挑台上的一部分阻挡来自大佛的全高碰撞箱，实测碰撞箱在这两个标高超出了佛身轮廓。

- A、B 用同一套暗灰棕门洞详图。以厅侧净门洞中线为基准，排齐洞壁开口、薄门楣、门侧内衬、门槛、踏面和挑台。现有壁画靠门的边缘可作为外框宽度的上限。由洞窟往上看，两侧板收成一面，挑台底面一块成形，与门侧齐收。
- 保留 2.00 × 3.10 米净门洞，统一轴线到洞室局部 z = −13 米。两层踏面分别与所在展厅的 +8.11 米、+19.58 米齐平，进出都沿同一条线。按两层实际佛身轮廓收紧局部碰撞，走到原有观景深度后仍有停步空间。人物、镜头、门禁与可见边缘共用同一组尺寸。
- 一楼楼梯入口现为 2.40 米净宽，扣除角色碰撞半径后，中心实际可走宽约 1.02 米。保留首梯后沿，向主室方向放宽 0.60 米，门槛、内衬和镜头边界随门口移。模拟可走带增到 1.62 米，需在贴近大佛底座的一侧再实走。门内向主室打暖金扇形光，地面有柔亮光斑。
- 验收视角取一楼仰视、主室斜看、两厅内侧和两层挑台回看。用键盘和横屏摇杆沿门中、左右各偏半步双向实走。锁门与开门各测一次，检查脚下衔接、镜头遮挡和楼梯口灯光。

## 四部壁画新配音

- 九色鹿和沙弥各切开场与五段局部。《五百强盗成佛图》切开场、七段局部及结语。《火宅喻》切开场、两段局部及结语，共 25 段。保留用户交付的原片，按录音核听切点。沙弥有数处「分段」口令连在上一句话后，需要手工复核字尾。
- 《五百强盗成佛图》使用与 SRT 对齐的 `500强盗皈依(1).mp3`。录音开头把概要和结语连着读，拆到演出的对应位置。其余各段用原有讲稿校正字幕，九色鹿两个小字差异按实读同步。
- 复用原有画框、推近、退回与快进。绘世厅保留现有画面布局，在有配音时以音频驱动字幕与下一步，无声时仍可读字幕。开场和局部播放时可快进，过渡阶段接管输入。每次仅加载需要的段落，失败时可继续浏览。

## 所有图鉴下载

- 三份现有图鉴共用「下载 PDF」入口。《绘世观壁笺》《敦煌观展手卷》《敦煌乐舞见闻卷》分别输出一份，使用游戏同一份正文、章节顺序与图源。
- A4 页面保留游戏里的浅纸色、纹样、棕色标题、左图右文。长卷整图横向排，窄幅整图留边，图注和正文跟随图片分页。保留可选择、可复制的文字。每份嵌入所需的图和字体，下载后离线可看。
- 用统一阅读内容在构建时生成 PDF。下载前无需请求 PDF，当前阅读器滚到哪里都不会影响导出的完整性。验收桌面下载、手机横屏下载与预览，以及整卷图片、分页、文字选择和实际文件大小。

## 两卷到手后开启第三馆游戏

- 两厅各自仍按原条件发图鉴。两份均领取后，在回到漫游时提示一次「游戏入口已开启。它就在一楼，自己去找找吧～」。已有两卷的旧档首次进入新版也点亮入口并提示一次。
- 从一层入口看向大佛，在左侧佛足外放金色圆盘，避开右侧楼梯通路。已用当前碰撞数据走通洞室局部 x ≈ −4.2、z ≈ −11.9 米的候选点，最终结合实景确认站位。复用第一馆向上流动的金光和减弱动态规则。靠近后可点圆盘进入游戏。
- 当前「壁画故事」主题没有可玩的关卡。建议先用现有拼图引擎做一关《九色鹿王本生》，沿用已验收原图。圆盘点入实际可玩的关卡选择，游戏退出回到第三馆盘边。与图鉴同用两卷解锁记录，直达入口也检查资格。
