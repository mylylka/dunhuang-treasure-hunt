# 第二馆室内、直梯与双层同行方案 v001

2026-11-05。状态：婧婧已回复“实施”，按本方案完成；实际尺寸、验证与试玩入口见 `docs/music-companion-two-floor-v002.md`。下文保留获批时的方案原文，适用第二馆乐舞坊及同行者原型。

## 推荐空间

采用“开放一楼后室＋后室东下西上单直梯＋左后二楼”，连接已有二楼乐人前廊。梯段零折返，到顶进入二楼时只转一次；不做多圈楼梯。

以下设计坐标均为music源坐标；当前主世界另有28°平面旋转和2.5米基础高度。

本次新增楼梯/平台不加可见栏杆，行走面保留完整脚印防坠边界。

## 已检查的空间余量

- v005仅更换庭院铺地，55个非庭院铺地网格的顶点、法线、索引与v004完全相同，可依据v004可编辑源工程核查建筑。
- 后墙内侧z约−27.75，东西内墙约x34.7625～59.4243。梯段横向范围z−26.6～−23.0；33°方案底端新增约0.69米仍无柱、门或乐师阻挡。下平台东边x58.1距东墙内面约1.324米；站位中心仍需内缩至平台完整支撑范围。
- 实网格15条向上射线确认，原35°候选梯段首先命中木天花y约13.5305米；改为33°后新增东端仍在同一无柱后室。梯顶到天花约5.615米，新二楼有真实净空。
- 一楼从门到东侧梯脚可以经右室通达，不必挤楼梯前后约1米的夹缝。候选通路为：前廊(39.5,−20.4)→门(39.5,−21.8)→后室(39.5,−23.4)→高处平台下(46.5,−23.4)→右室(46.5,−20.4)→(56.8,−20.4)→下平台(56.8,−24.8)→梯脚(55.69,−24.8)。
- 上平台和高处梯段下方须保留一楼穿行空间，不能实心填筑；楼板下净高约5.626米。最终须用人物真实碰撞及镜头实走复核，当前空间核查不替代可玩验收。

## 双人行动与上下楼辅助

1. 一楼、二楼宽处继续侧前方并排行走，横向约1.6米、领先约0.4米；步行、跑步、停步沿用现有Walk/Run/Idle。
2. 3.6米宽楼梯提供双人通道，沿实际梯面和两条安全路径连续上下；门口、转角或通道不足时短暂错位/依次通过，到宽平台恢复并排。不为抢前位强行穿过玩家，也不在坡上强制调头换队。
3. 玩家和同行者各有独立楼面ID与脚下高度，按连通的行走面寻路；楼上楼下同一平面投影不相互误挡。同行者不能直接朝玩家XZ坐标跨空洞或穿楼板。
4. 梯口与梯段显示“上楼 / 下楼 / 停止”，电脑及手机均可点；沿碰撞安全路径逐帧行走，到一楼/二楼宽平台停靠。同行者一起行走。手动移动立即接管，暂停、失焦、离页取消辅助；中途可停，可改向，不瞬移。
5. 相机继续由玩家控制，新增楼板、墙洞、梁及梯底参与高度正确的相机碰撞；辅助只作缓慢朝向调整，不突然甩镜头。手机按钮不盖摇杆、已有故事/对白触点，必要触点至少44px。
6. 现有测试对白保留在一楼指定区域；本次不扩写正式导览内容。

运行时统一为“选择本区域行走面移动→按身体高度处理人物间距→更新各自楼面”，解决当前companion平地分支会覆盖多层移动结果的问题。NPC平层仍用本层A*，跨层必须经过楼梯连接图；不把所有房间混成一张XZ平面。

新原型先沿用每次刷新两人回到共同安全起点，避免只恢复玩家到二楼而同行者留在一楼。若后续需要持久恢复双方位置，单独定义楼面版本兼容规则。

## 实施与验收顺序

1. 建门洞、楼板、直梯与平台灰模；测净宽、坡度、净空、楼面边缘和入口→梯脚的实际通路。
2. 开放玩家一楼室内、直梯与二楼；检查楼板上下同投影、梯底通行、头顶碰撞、开洞和镜头。
3. 接入同行者的独立楼面/高度与跨层路径，复核并排、窄门错位、跑步、停步、反向及双方不互锁。
4. 接入上下楼辅助，复核上下行、中途停止、手动接管、暂停/失焦、两人共同到站，提供实际计时。目标正常步行含进出约6～8秒，最终以试玩为准。
5. 做电脑和手机横屏触控模拟的真实路线检查，以及相关规则测试、类型检查、独立入口构建。仅对抽取内核做必要的九层楼辅助定向回归，不跑2D或全地形回归，不把模拟检查称作实体手机验收。
