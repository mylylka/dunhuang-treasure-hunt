# 纹彩院墙面素材：现有接入与可选补充

2026-10-31，用户要求内外墙接近概念图的纹样丰富度。

## 当前可以直接完成

项目已有用户提供的完整莲瓣团花、葡萄莲花、葡萄石榴图，清晰度足够制作样片墙面。v002复用这些图的完整正方形纹样和有记录的花叶边带，替换v001简单菱形；用于后墙、侧墙、院外墙和梁枋。正方形图保持比例，不强拉成长壁画。来源登记为`art-source/world/wall-decoration/v001/source-manifest.json`。

这能解决墙面空白和花纹过于简单的问题，但并非从概念图中原样取出的那幅壁画。现有厅堂概念图的后墙花纹被人物、植物和桌案遮挡，侧墙有透视压缩；直接放大裁切无法得到清晰、完整的原样纹理。
