# 莫高窟 v009 修订验收

独立预览：http://localhost:4216/ 。可用 `?view=passage#/` 从洞口进入，`?view=interior#/` 直接观察入厅提示。v008 的 4215 服务和全部源资源保留。

## 本轮落实

- 千佛：侧墙后端不再跨周长 UV 接缝；每排高 2.05 米，壁画上缘从完整佛像行的边界起铺。深处补画区与上方同尺寸、同相位；后墙底排也保持完整。
- 闪烁：入口两块地面改为 7 米处对接，消除 0.1 米重叠；山体内腔与殿内墙留净距；墙顶厚度导出为实际几何。门框改素色石质收口，花带止于门框外缘。
- 大佛落地：新增最高 0.26 米的低矮承托层，轮廓取自原模型底部，使用暗色地面材质衔接。佛像网格、原 UV、35 米尺度不变，承托层完全位于原有不可走入的碰撞范围内。
- 光照：复用洞内光照及入洞适应；壁画、花带仅校准反射颜色，没有增灯、自发光或改变原图。外景不受影响。
- 入厅：跨过真正室内区域后停步两秒，暂停/后台不计时；随后显示可点击的上、左、右半透明箭头。上箭头仰望大佛，左/右转向相应壁画；行走或操作镜头后提示消失。离厅再进入重新提示。
- 抬头键：R 抬头、T 低头、C 平视。按钮同时标注；WASD、方向键及 Q/E 保持原职责。
- 九色鹿：完整长卷展开后先播放用户提供的整段导语，字幕完整显示，后接原五段故事；空格跳过导语仍从第一段开始。

- Blender 读回源工程审计：墙面 UV 无跨圈插值、完整行边界、入口地面无交叠、承托层不侵入通道、佛像高度与保护资源哈希均通过。报告：work/world/mogao-v009-geometry-audit.json。
- Chrome 实际网页：正常走进洞口；停步计时、暂停冻结、再次进入、三个箭头和 R/T/C；导语 18.18 秒实际播放至 ended；整段字幕、暂停/重播、空格跳过、五段故事及第三段双图、结束选择通过。
- 横屏 844×390 完整导语与控制区无越界；竖屏仍阻止游玩。正式首页入口检查未加载新莫高窟模型。
- 左右狭通道及门口行走、Q/E 转镜截图与录像保存在 work/world/mogao-v009-motion-*；检查中未看到原先的交错条纹、门边彩色细线和地面重叠线。
- npm run typecheck、npm run test、npm run build 与独立构建通过。原规则 355 项及新增 4 项均通过。未重跑与本轮无关的全部小游戏浏览器测试；正式首页退出探索/主题入口单独通过。
