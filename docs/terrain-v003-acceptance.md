# 地形样片 v003 批注修订与验收

2026-11-02，仅修改3D。对应用户七处浏览器批注；v001/v002交付与原模型保留，4222本地服务指向v003。

## 变化

1. 纹彩院两侧外墙各移出2米，后墙和前翼墙接长，新增两侧铺地复用原材质；主楼、院门、藻井、家具保持原尺寸。20幅侧墙纹样随墙移动，12幅前翼图案只重排、不拉伸。贴墙花盆、玩家碰撞、镜头碰撞与平地范围同步。
2. 上坡约10米开始极轻微听到原有乐曲，近处逐渐增强；默认40%总音量下，首次可听约0.0027增益，近门约0.366。原台词“哪里来的音乐声？”在真实可听WebAudio播放累计2.5秒后触发；静音、暂停、后台、加载失败与低于可听阈值均不累计。使用原语音/乐曲，不新增合成声音。
3. 地形模式启用对数深度缓冲，解决百米远景厘米级楼门窗装饰层的深度精度不足；水和飞天薄雾的自定义着色器同步兼容，旧地图保持原深度配置。保留楼模型和材质原件。
4. 40株可见户外草丛按实际缩放后的完整模型范围检查，21株移至更外侧。与道路、台阶、院内及湖岸保留额外1.1米间距；不靠隐藏或缩小草掩盖。台阶左角穿插已消除。
5. 乐舞坊左侧旗幡及配套桌凳转至院前左侧，树根处的笛桌及两盆一并让开。合批网格按完整部件变换，10,080个顶点移动、未切断三角形；玩家和镜头代理读取同源变换。
6. 从两款用户树模型中采用`tree 3d model.glb`，按原比例统一放大至34米，主干分叉约接近楼顶，覆盖屋顶的枝叶高于18.1米。树在楼左前侧，几何与楼/屋顶保守范围相交为0；低根玩家范围、中干镜头范围、上冠淡化范围分开。原件与运行GLB字节完全一致，原2K纹理未重编码。
