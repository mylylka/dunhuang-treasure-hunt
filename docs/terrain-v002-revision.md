# 地形样片 v002：缩短路线、恢复通行与九层楼高树

## 实施约定

- 纹彩院到乐舞坊的实际中心线路长从267.28米缩到约三分之一，目标85～95米。通过缩短建筑间距、收紧连续坡面和去掉大U形绕行实现；保留院落山腰→更高坡顶→低谷的关系，不将短路改成陡直台阶。高度绝对值允许随短路线重新配平，真实遮挡仍需验证。
- 湖边到九层楼以平滑直接弧线接原台阶中线，取消直角和无必要折返。保留上一轮红圈所示右前方崖体、朝左后方的门面，以及两院不同朝向；现有建筑尺寸不变。
- 初始位置在纹彩院门外的引路上，面对院门，使用新的独立会话键，旧样片会话保留。
- 地形模式跑速由4.4提高到7.0米/秒（约提高59%），普通步行保持1.8米/秒；角色步频需同步，移动碰撞保持小步检查。旧样片速度不变。
- 定位用户所指出的崖前卡住处，检查道路侧缘、斜向移动和台阶接缝，不通过关闭碰撞或放宽所有坡度限制绕过问题。
- 九层楼两侧使用用户提供的树GLB，各高约25米；原模型按实际包围盒等比缩放、底部落地，不AI重绘。树干/树冠范围纳入通行与镜头检查，避开门面、台阶和主路。
