# 美术样片v002：试玩反馈修订

2026-10-31。承接用户七条页面批注与岩石、灌木、树冠变化要求，继续停留在美术样片验收阶段。

## 本次修改

| 反馈 | 根因/处理 |
| --- | --- |
| 门柱石基一圈闪烁 | 原红色柱身侧面与石基侧面共面。柱身现在从0.5米石基顶起建，侧面不再重叠；装饰贴面与墙体保持0.035–0.04米距离 |
| 树木、罐和石头穿模 | 新增21个共享圆形实体代理，来自与Blender建模相同的`courtyard-props.json`。树冠与灌木不阻断行走 |
| 经过门楣、廊顶长时间整屏遮挡 | 旧镜头仅检测灰模顶板，未覆盖正式屋檐和4.78米藻井。现由模型导出56个逐结构包围盒；门厅自动采用低位短臂，受阻调整肩侧角度，平滑后再次碰撞约束；挡视线的独立树冠局部淡出 |
| 内墙、侧墙、外墙简单 | 使用项目已有完整莲花、葡萄莲花、葡萄石榴纹样；后墙、厅堂侧墙、院墙内外面和梁枋增添花叶装饰，替换简单菱形。完整正方图保持比例，长条只采用登记裁片 |
| 远山要切面且连绵 | 自建非索引三角网格，逐面法线；18块宽幅山脊相互搭接形成天际线，8块北侧岩壁保留完整碰撞范围 |
| 岩石形态、大小要丰富 | 10块切面石头包含单体、大小岩组、扁石；修复首次生成时朝内法线导致的阴影条纹，所有岩石封底、法线向外、无重复三角面 |
| 岩上黄绿灌木、树木高低错落 | 13组不同尺寸黄绿灌木，其中5组依真实岩石三角面射线落点定位；7棵树高度约3.2–7.2米，冠幅约2.1–5米，逐棵布局和造型参数独立 |

道具相机碰撞按有限圆柱求交，避免把圆形大岩扩大成方箱后，在可行走的斜角位置错误地将镜头挤到人物体内。

## 墙面素材边界

本轮装饰来自用户已有的AI教学图稿，能提供清晰完整花纹，但并非概念图中后墙壁画的原样复原。概念图内的植物、人物和桌案遮挡了图案，透视裁切不能恢复缺失像素。
