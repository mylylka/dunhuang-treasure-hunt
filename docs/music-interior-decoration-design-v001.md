# 第二馆一、二楼整体装修方案 v001

2026-11-05。状态：婧婧已回复“好的实施”，本方案已批准；实施记录见 `docs/music-interior-decoration-v001.md`。配色与构件关系图另存 `work/world/music-interior-decoration-design-v001/`，下文保留获批方案。

## 整体方向

延续游戏已有的敦煌风格：**暖米砂灰泥、朱砂木构、矿物青绿、少量花叶彩绘与赭金细边。** 室内以浅墙、清楚的木石分区和局部照明形成完整空间；入口、楼梯和二楼用同一套边框与颜色相连。原飞天画、乐人及窗格作为乐舞坊的既有重点。

现状的主要问题不是空墙数量多，而是大面积同色棕墙、棕顶和缺少局部光线，使门洞、转角与高低空间不易辨认。首版先完成所有可见建筑表面的材质、分色和收口；墙面用已存在的花叶边带组织构图。正式新壁画内容仍由后续素材决定。

## 材质与配色

- **主墙**：温暖浅米砂色、哑光灰泥，只有轻微细纹理。提亮室内底色，保持足够留白供原有画面和人物突出。
- **低墙裙**：偏灰的浅矿物青绿，参考高约0.75米；上沿用窄赭红和米色线收口。到门洞、楼梯和楼板连接处分段，不能从门洞中穿过去。
- **梁、门窗收边**：朱砂木色与青绿少量配合，深木色作为顶面衬底；既有柱和窗格局部清理分色，移除的一楼中柱不恢复。
- **一楼地面**：暖灰米色的大块石板，细缝、平整，室内板块与前廊连续；不做凹凸碎石，不用高对比花地毯占满通道。
- **二楼地面**：温暖浅木板，整合新后厅、梯顶与原前廊的木色，木纹保持低对比、方向明确。
- **细部**：赭金仅用于窄边，保持哑光。花叶带复用当前第二馆梁枋已经使用的 `public/assets/world/courtyard/v002/wall-floral-border.jpg`，保持图案比例与方向，不拉伸成长幅新壁画。

配色示意图是选色关系，实际渲染色以游戏光照下的对照画面为准。

## 分区落位

| 区域 | 首版具体处理 | 完成后玩家看到什么 |
| --- | --- | --- |
| 一楼前廊及门洞 | 浅墙、统一门侧与门楣收边；花叶窄带落在门楣或现有梁面；剩余木构分色；石面连续过门槛 | 入口完整、能一眼识别开放门洞 |
| 一楼后室、左右侧墙 | 暖米砂主墙＋浅青绿低墙裙＋细线；长墙按原墙角/梁位分段；大面积墙面与地面形成明暗层次 | 从棕色灰模转为有组织的乐舞馆室内，转角和通道清楚 |
| 飞天墙室内背面 | 用同系墙裙、窄花叶带和墙顶收边完成背面；面向庭院的原飞天画及其显示逻辑保持 | 内外连贯，背面完成建筑装修而不覆盖原画 |
| 直梯、上下平台 | 暖米石踏面、稍深踢面和细踏沿；平台与相邻地面整合；梯侧墙花带沿水平结构分段；不逐阶铺花纹 | 上下方向清楚，行走时视觉安定 |
| 梯下与楼板底 | 浅暖墙、偏浅的木/灰泥底面、少量柔和补光；门洞和穿行净空完整保留 | 梯下通道看得清、可以与同行者经过 |
| 二楼新后厅 | 继续同系浅墙与低墙裙，温暖木地面；上沿少量花叶彩绘；门洞明确收口 | 到达二楼能辨认后厅、楼梯口和通向前廊的门 |
| 二楼原乐人前廊 | 统一新旧木地面接缝、墙框、窗边和顶部颜色；原乐人、窗格及既有开放立面作为重点 | 前廊与新后厅属于同一馆，既有内容更清楚 |
| 顶面及高墙 | 木底适度提亮；梁枋以朱砂、青绿和少量既有花带分层；高墙装饰跟随实际楼面/梁高，不能套成所有地方一样高的框 | 能读懂一楼、二楼和高处屋顶的层次 |

对应装修清单的一楼6组、二楼4组墙面全部覆盖。隔墙的两侧、门窗侧口、墙角、梁、柱脚、楼板底和斜梯底都包括在首版内，不只处理主要正面。

## 照明与陈设

增加约4—6处柔和的暖色局部补光，重点是入口内侧、后室主墙、梯下、梯脚和二楼到达处；新增灯不投实时阴影，现有室外太阳方向和整体曝光保持。先以光线和表面装修改善可读性，首版不新增占路的大型家具或展柜。

目前第二馆没有专属室内补光，顶部较暗。灯光强度须以人物、墙面和原飞天画在实际游戏中可辨认为准，避免黄光把所有材质重新染成同一棕色，也避免亮斑、闪烁和过曝。

## 本次确认覆盖的范围

确认后实施内容为：建筑材质、轻微灰泥/木石技术纹理、现有花叶窄带复用、薄收边和局部灯光。不会由Agent生成新的正式乐舞壁画、重画飞天或编造展陈文化内容。已移除中柱、原有门洞与窗、直梯尺寸、楼板高程、两人通路和辅助上下楼继续作为空间边界；装饰薄层原则上控制在约3厘米，任何实际突出占用通道的地方都要同步检查人物和镜头。

## 实施方式

从 `art-source/world/models/music-interior/v002/music-pavilion.blend` 非破坏派生下一版 `music-interior/v003`，原源模型和运行GLB保留。现模型按材质合批，同名灰泥/木材还用于外立面等部位，不能全局改色；需按源坐标、朝内面和连通构件分离室内装修组。

确认后先更新目录约定，再建立：

- 共享装修配置：`src/content/world/music-interior-decoration-v001.json`；
- 模型构建：`scripts/build-world-music-interior-v003.py`；源/运行模型按 `music-interior/v003/` 保存；
- 材质与灯光模块：`src/world/music-interior-decoration.ts`，需要的运行技术纹理另存版本，记录来源；
- 原型继续使用 `music-companion-v002.html`，装修只接入第二馆双层同行预览；
- 检查、截图对照与性能记录：`work/world/`；交付记录：`docs/`。

装饰与灯光在环境静态阴影准备之前加入；复用纹理和材质、避免每段墙各下载一张大图。首版不要求改变移动/寻路架构。

## 验收

对照入口、一楼后室、梯下、梯中、二楼后厅与乐人前廊六处同位置画面；检查花带方向/比例、墙角接缝、地面共面闪烁、薄饰面穿模和顶面亮度。实际走完一楼进屋、双人步行/跑步上下楼、二楼前廊与返回，复核上下辅助、镜头和手机横屏。运行相关类型、资源和独立入口构建检查；不跑2D或全地形回归。
