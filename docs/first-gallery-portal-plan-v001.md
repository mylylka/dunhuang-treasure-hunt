# 第一馆手机进场与画卷入口方案

2026-11-06。待确认，现有试玩仍提供当前版本。

## 让玩家先走起来

用现有 4229 入口做手机横屏冷缓存测试。667×375 Chromium 仿真在本机回环约 2.41 秒可操作，但在开放操作前已请求 58 项资源、传输约 137.5 MB。以 35 毫秒延迟和四倍 CPU 减速测试，下行 67.1 Mbps 时约 20.5 秒可操作，下行 16.8 Mbps 时约 32.5 秒显示加载失败。当前首屏同时等三馆的模型、环境阴影预烘焙和壁画遮罩。仅第三馆山体、内景、佛像和塔楼就约 59 MB。

1. 按玩家实际出生或恢复的位置确定首屏。第一馆优先载入人物、近处院落、地面、碰撞和当前可见的主要陈设，让第一帧可走、可转镜。已有二馆或三馆站位的存档优先加载对应位置。
2. 第一馆可见的远景先保留足够辨认的轮廓。第二、三馆精细模型、内景、树和驼队按距离或通行资格预取。靠近未就绪的入口时给局部提示，真实楼面和碰撞可用后再开放入口。壁画原画和已完成进度优先恢复，后续特效用的遮罩可以分批准备。
3. 分开记录下载、模型解码、场景准备和可操作时点。评估版本化 GLB 的预压缩，以及关键模型中体积最大的几何和贴图。高精度画架面和主要原画保留清晰度。使用同一条件对照冷、热启动，先验收同样的限速下能稳定进入，再比较首屏传输和等候时长。

## 西侧庭院的三件陈设

| 对象 | 当前实测 | 拟改 |
| --- | --- | --- |
| 西侧长桌与台面摆件 | 桌心约 `(-19, -3.45)`，偏转 10° | 归到庭院轴线的 0°，与墙和台阶平行。桌上纸张、笔、碟跟着一起转。 |
| 六格画架 | 宽 1.05 米，高约 0.98 米 | 以脚底高度为基准，等比放大到宽约 2.10 米、高约 1.96 米。用已找到的同款更清晰原件重新配准六格图案。 |
| 颜料小柜 | 宽约 1.45 米，高 1.50 米 | 以脚底高度为基准，等比放大到宽约 2.17 米、高 2.25 米。木色略提亮，保留木纹与颜料原色。 |

以目前院落 v006 为基础另存派生模型和碰撞布局。画架、小柜先保留朝向，若扩大后挤压通路，只在原区域微调。同步核对脚底接地、墙和柱净空、取色站位、桌边交互区及相机。六格画架使用已找到的 `02_easel_grid4.png`，重新取正彩绘面后保留原六格及边框。东侧用于正式设色的画架单独区分。

## 第一次通关与永久入口

按当前第一馆三项通关理解本次「所有的第一关」。借物补画三处、三兔共耳和画架作品提交全部完成时，即解锁桌上摊开的画布。光效和点击位置固定在真实桌面画布，六格画架继续作为展品。

1. 最后一项完成后先走完它本身的收尾。壁画播完总结、藻井退出放大观察，或者填色回庭院完成挂画反馈后，小旅人再自动走到西侧画卷台。途中使用实际可通行的路径，避开长桌和放大后的柜架。暂停及手机转屏时停在原地，恢复后继续。若选择「跳过带路」或遇到不可达位置，在原地告知已解锁和画卷方位，然后归还控制。
2. 到桌前停下，朝向桌上画布。以短字幕和解锁面板正式告诉玩家「第一馆通关！游戏世界已开启。」桌前可选「进入游戏世界」或「继续探索」。点击进入直达现有纹样小游戏选择页。
3. 带路只由本次实际完成最后一项触发。已通关旧档直接看到入口亮起。首次提示结束后，重进庭院或返回画卷台都可自由走动和主动点击画布。保留现有三项进度和一次性通知记录。

光效取参考图的暖金细丝、回旋光弧和碎金。刚解锁时沿纸面纹样亮起，到桌前给一次较强的短演出，中心有柔和上升的细金丝，周边光弧一层层展开。常驻状态收为低矮慢流光和细光尘，能在庭院里辨认，也看得清纸面画。用贴近画卷的少量三维面片、曲线和合并微粒实现，减少动效时保留静态金光。

## 验收

- 冷启动记录桌面和手机横屏可操作时点与首屏传输量。检查重复进入、保存位置恢复、远馆接近时加载、首馆三项各自可玩。
- 同机位对照桌边与台阶的平行关系、放大倍率和纹样清晰度。走通桌前、柜前和院门。
- 分别以壁画、藻井、填色作最后一项实测带路。检查手机转屏、跳过、旧档、重进、重复点击和未通关门禁。截录首次与常驻光效。测试与实景证据沿用 `work/world/first-gallery-v001/`。
