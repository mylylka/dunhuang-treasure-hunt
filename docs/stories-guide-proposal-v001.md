## 2. 每屏内容

下列文字为教学结构和拟采用的要点，不是已经发布的课程。页签建议：看全卷、九色鹿、沙弥故事、图像边界、小考。长正文只在面板内部滚动；图片保持完整比例，沿用通用“放大查看”和独立观察窗。

### 第一屏：先看全卷，再找局部

- **具体图片**：`public/assets/world/story/v002/full-scroll.webp`（4096×682）；通过图片切换查看`public/assets/world/novice-story/v001/full-scroll.webp`（2172×358）。不把两张宽卷缩成同屏小缩略图。
- **教学要点**：先观察整幅图的横向连续性，再按人物、动物、建筑和动作寻找局部。局部图是帮助观察同一画面的放大材料，不是额外发现的一幅独立壁画。用现有定位矩形连接全卷与一张局部，标注只作界面覆盖，不写入原图。
- **来源**：D1、D2、N1、N2；事实说明仅限本地已确认的文件关系与可见画面。
- **不推断内容**：不能由游戏分段数推定原壁画本来就有五格；不由缩略图颜色或缺损形状推断颜料、年代、修复状态。

### 第二屏：九色鹿图中的情节位置

- **具体图片**：默认完整九色鹿长卷；可选现有`rescue-and-promise.webp`、`queen-and-betrayal.webp`、`appeal-to-the-king.webp`三张局部，均位于`public/assets/world/story/v002/`。定位复用`nine-colored-deer-v002.json`对应region，不新填一套坐标。
- **教学要点**：将“救人和立誓”“王后索取鹿皮及告密”“鹿王陈情”等已采用情节与画面位置对应；比较同一主角在不同动作场景中的再现。让学生先描述看到了什么，再结合故事文本理解，不要求只凭图像猜完整因果。
- **来源**：D2、D3、R1；“两头开始、向中部推进”的具体阅读方向在R1复核后才写入正式正文并配置方向标记，复核前不出方向判断题。
- **不推断内容**：不说游戏五段就是原画固定分格；不把故事中的报应情节当作现实规律；不由游戏画面推断真实动物、人物的历史身份。

### 第三屏：沙弥故事怎样连接多个场景

- **具体图片**：默认沙弥完整长卷；可切换`ordination.webp`（1836×857）、`confession.webp`（1436×1600）、`fine.webp`（1645×1700），均位于`public/assets/world/novice-story/v001/`。使用N2已有全卷定位；竖幅局部完整等比显示，不硬裁成横图。
- **教学要点**：根据现有故事配置，把“出家学习”“少女向父亲讲述经过”“父亲向国王说明事情”等场景在长卷中定位，观察人物姿态和建筑如何组织不同片段。区分图上直接可见的动作与需要文本解释的事件背景。
- **来源**：N1、N2；宗教名词、经籍来源及历史制度在独立权威资料复核后另加短注，当前不作扩写依据。
- **不推断内容**：不从画面直接断言当时普遍法律、社会习俗或全部佛教戒律；保留既有演出中“悲惨选择”的叙事边界，不将故事中的自我伤害当作学生应仿效的价值要求，小考不以复述该行为为目标。

### 第四屏：画面能告诉我们什么

- **具体图片**：两卷原有完整图按页内切换查看；配一条简短资料说明，不新增3D截图或AI对比图。引用前屏局部时仍用同一文件。
- **教学要点**：用三种明确标签区分“图上可见”“故事文本解释”“游戏表现”。例如可见人物与动作来自交付图；完整因果来自故事讲述；悬浮长卷、定位框和前推放大属于游戏观察方式。说明当前探索空间为创作组合，两幅图在游戏里的左右墙位置不构成真实洞窟布局证据。
- **来源**：D1、N1的文件身份记录；`docs/development-handoff-2026-11-02.md`已确认的创作空间边界；D2、N2的处理登记。资料区提供R1，标明用途和待核限制。
- **不推断内容**：不把用户图统一标成实物照片，不把游戏建筑称为实景复原，不据当前光照判断原作颜色，不声称这四屏涵盖佛教或敦煌宗教文化全貌。

## 3. 可跳过小考

四题分别对应四屏，只检查参与和观察方法，不声称掌握完整文化知识；可随时跳过，跳过不伪记学完。

| 题目方向 | 正确理解 | 反馈重点 |
| --- | --- | --- |
| 全卷与局部图是什么关系？ | 局部图帮助观察完整图中的对应区域 | 可在全卷定位，不是新的一幅独立壁画 |
| 看到同一主角在不同场景出现，应怎样理解？ | 结合动作、场景与故事文本核对情节 | 不单凭数量把它们当成不同角色 |
| 哪项判断需要额外资料？ | 经籍来源、具体年代或当时通行制度 | 图上动作可观察，历史结论需要出处 |
| 游戏中长卷悬浮、前推放大说明什么？ | 是帮助观看的游戏表现 | 不能据此证明历史洞窟有这种展示方式 |

四题选项与反馈须在实施时随正式正文一并审阅；不考未经复核的壁面方位、年代或经籍篇名。

## 4. 路由与实施边界

- 复用现有TeachingScreen、放大观察、资料弹窗与独立学习记录；不复制3D播放器、不改旧进度/作品存储、不创建账号或数据库。
- stories目前零正式小游戏，主题选择和结束页不能因导览上线改称“全部内容完成”。若沿用现有顶部“直接玩游戏”，其跳过去向只能是明确标记筹备状态的stories游戏区，不能生成可玩链接；同时保留回探索。该文案与去向应在本提案确认时一并决定。
- 确认后再编写`src/content/lessons/stories.ts`及必要的正式素材索引；先核查来源和图片身份，资料不足的断言删除或保留待核，不抢先开放课程。
- 原图、当前故事版本、临时音频及旧预览均保留；需要新派生时另存版本并登记。只有确需新增目录约定才单独提案，本文不修改AGENTS。
- 验收包含：四屏及小考内容与图片对应、全图/放大、跳过不记完成、保存失败重试、stories筹备状态、从石窟返回原位置、电脑及手机支持尺寸无页面级滚动。按实际改动运行内容校验、类型、规则与串行浏览器检查，不凭路由可达宣称课程验收通过。
