# 3D探索世界素材与模型约定

本文件对应 `codex/3d-world` 分支的灰模阶段。灰模用于验证空间、行走、镜头和跨页面返回；用户确认灰模后再制作正式美术样片，样片确认后扩展完整世界。

## 来源与目录

- 用户素材库：`Downloads/3d视觉素材库`，本次清点27张图。
- 本轮仅归档并派生九色鹿全卷、救人立誓、鹿王陈情三张图。其余24张只检查和登记，不改用户原文件。
- 归档：`art-source/world/nine-colored-deer/v001/`，保留原文件名、原字节、原尺寸；`source-manifest.json` 记录 SHA-256、运行路径、尺寸与处理方法。
- 运行：`public/assets/world/story/v001/`，只做EXIF方向校正、RGB转换、等比缩小和WebP编码，不裁切、补绘或擦除内容。
- 再生成：`python3 scripts/prepare-world-preview.py '/素材库路径/3d视觉素材库'`。脚本遇到同名版本字节不同会拒绝覆盖；新输入应新增版本，不覆盖归档。
- 暂不清理任何旧素材或中间成果；清理遵守项目删除审批规则。

## 飞天补底的采用边界

原母图和补底图都为1448×1086，整体构图可对齐，但补底图全幅存在AI改绘。正式画面必须以原母图为底，不能直接换为补底图。

两处自由端使用原母图像素分层：左上红/蓝飘带的外侧短末端、左中绿色飘带的最外侧短末端。连接处固定，人物与其他纹样静止。补底新出现的截断尖尾约在 `(41%,23%)` 与 `(23%,39%)`，须留在原图静态连接部分下面，不得在摆动时露出。完整运动周期复核无双影、尖尾残影与接缝后才接入；需要更大摆幅时向用户请求局部v002，不扩大采用AI重绘区。

## Blender / GLB制作与导出规范

- 尺度：1单位=1米。Blender制作时Z向上，GLB导出转换为运行端Y向上；不得在Three.js再次重复旋转整场景。
- 原点：建筑区域模型以入口地面为原点；公共道具以落地中心为原点；角色以双脚间地面为原点。区域摆放坐标由数据配置决定，不烘焙进顶点。
- 节点：英文kebab-case稳定ID；公共部件按几何/材质复用，不给每根柱子复制整套纹理。
- 区域：纹彩院、乐舞馆、洞窟分别导出；共享角色与道具独立。避免一个巨型GLB包含所有正式世界。
- 碰撞：视觉网格与简单代理分开。墙体、柱体、不可通行坡面使用命名碰撞代理；台阶提供连续行走代理；小摆件不默认全阻挡。二楼没有可达行走面。
- 角色：动作名固定为 `Idle`、`Walk`、`Run`；原地循环动画，前进位移由运行器控制。检查脚底高度、循环边界和背包/披肩穿模；首版不加布料物理。
- 材质：glTF标准PBR，正确区分sRGB颜色贴图与线性法线/粗糙度；需要的程序效果先烘焙，不依赖仅Blender能执行的节点。不要烘焙用户界面文字进纹理。
- 图片：母图归档保真，运行纹理按实际视距派生；故事平面保持原比例。未来GLB、声音、贴图使用独立世界资源索引，不伪装成2D关卡图片。
- 生命周期：区域资源拥有明确释放者；共享纹理只在最后使用者退出时释放。离开3D停止渲染/输入/长音频，返回才重建。
- 发布兼容：URL统一经 `worldAssetUrl()` 拼接 `import.meta.env.BASE_URL`，不得写死站点根 `/assets/`。模型加载失败时保留直接选主题与重试入口。
