# 世界地貌、固定斜阳与地面材质讨论 v001

2026-11-03。用户已认可当前主行动线的缓坡波动。本轮制作独立 Blender 样片供讨论，正式地图、角色、建筑、碰撞与道路均不修改。样片不是现有游戏截图，也不是已完成接入的效果承诺。

## 先固定空间关系

- 第一馆＝绘彩馆／藻井馆／纹样馆／图案馆；第二馆＝乐舞坊／乐舞馆；第三馆＝九层楼／莫高窟。
- 主道路、路旁可自由走动的缓冲带、三馆院落和进出通道保留已确认的坡度与畅通性。地貌设计不仅避开路中心，还须避开完整路宽和跟随镜头活动空间。
- 第一馆到第二馆的视线外侧布置连续大沙丘，利用宽缓迎风坡与较陡背风坡形成清楚脊线，保留上坡、越岭、下坡的发现顺序。大体量不是一群独立尖山。
- 第二馆谷地以开阔沙地、少量沙砾和岸边变化为主，避免用岩石填满湖区或挡住乐舞坊。
- 第三馆外围逐渐过渡到戈壁及广域岩群：宽厚风蚀台地为主，少量高峰作节奏，大、中、小岩体成簇与疏旷空地交替。第三馆主体崖壁和九层楼仍是主要地标，不让背景群岩抢走所有识别度。
- 两张新参考图分别参考暖色光照与岩峰剪影、宽厚分层风蚀岩体及远近疏密。不直接把带场景光影的照片投影到模型上，也不移植图中的仙人掌。

## 当前影子现象的代码依据

当前 `src/world/art-sample.ts` 每帧平移太阳与其目标，两者相对方向保持 `(-14,35,22)`，所以太阳没有昼夜变化。按北为 Three.js 世界 -Z、东为 +X，现有太阳方位约212.5°，仰角约53.3°。

局部实时阴影图随人物／镜头跟随焦点移动。普通区域为光源正交投影平面的130×130米，第三馆区域为190×190米，分辨率2048×2048。建筑离开覆盖范围时没有该阴影图提供的投影，接近后重新进入覆盖范围；没有专门的院落阴影淡入逻辑。这是当前兼顾近景精度与成本的实现取舍，不是固定太阳世界必须采用的表现。

`src/world/terrain-scene-v001.ts` 的连续地形只开启 `receiveShadow`，未开启 `castShadow`。因此沙地能接到树、建筑的影子，却没有沙丘之间互相遮挡的投影。法线朝向导致的基础明暗仍然存在，不能把两者混为一谈。

`src/world/geometry.ts` 的半球补光为1.65，太阳强度为2.4；强补光托亮背阴面，加上接近的沙色和色调映射，削弱整体对比。九层楼与崖壁使用受光照的材质，已开启投影与接影，问题并非所有模型用了无光照材质。这里的灯光数值不是可直接相除的亮暗比例。

## 样片采用的固定太阳

- 方位：西北315°；高度：离地平线30°；全年景保持，不跟随相机转向，不设计昼夜。
- Three.js 指向太阳的单位方向：`(-0.612372, 0.5, -0.612372)`，Y向上、北为-Z。
- Blender 指向太阳的单位方向：`(-0.612372, 0.612372, 0.5)`，Z向上、北为+Y。
- 平地上的影子指向东南，影长约为物高的1.73倍。坡地上的长度随表面形状变化。
- 阳面为暖金沙与暖砂岩，阴面由较冷的天空补光照亮，保持可读，不压成黑块。颜色差别由统一光照和地形朝向产生，不在沙地底色中画死一边亮、一边暗。
- Blender 的能量和色彩管理只用于此次样片；接入网页时需实测匹配视觉，不能照抄数值便声称相同效果。

## 正式接入建议：静态环境先算，人物实时算

太阳和环境不动，确实适合提前计算环境阴影。将地形、山岩、建筑与固定树木的遮光关系按地块／资产预计算；环境可见时相应阴影数据便已就绪，不依赖人物走近才出现。角色和真正运动的物体仍需实时阴影，角色影子的方向与环境一致。

建议保留底色、法线、粗糙度为可复用材质，把固定太阳遮光与环境遮蔽存成独立数据；地形按分块UV或世界坐标取样，建筑按独立UV取样。固定太阳的直接光与天空补光分开处理，合成时避免烘焙光照和实时直射光重复照亮，也避免同一片阴影重复压黑。阴影遮罩不是把原材质永久涂黑。

这是完整世界的实施方案，不能用一张放大到整世界的2048实时阴影图代替，否则只是用模糊阴影换取覆盖范围。静态对象改变位置或外形后重烘焙受影响区域；原始材质仍可换。地形远景允许低密度网格与低分辨率阴影，近景保证柱脚、台阶和岩石接触清楚。资源分块与预加载根据视野安排，不能继续把人物距离当作远处建筑阴影是否存在的开关。

## 三种地面样张的用途

1. **纯沙**：第一馆周围沙坡、大沙丘主体，细小风纹和柔和颗粒，不像海浪或瓦楞板。
2. **沙砾**：道路外缘、坡脚、沙丘向岩区的过渡，沙为底，碎石疏密有变化。
3. **戈壁**：第三馆外围及岩群间谷地，以紧实细砾和少量较大碎石为主，色调更克制、更偏灰褐，但仍与暖色世界统一。

不建议三种贴图画出硬边分区；接入时根据地形区域、坡度与低频分布遮罩混合。远处保留大色块和地形阴阳面，近处再显示砂粒，避免整个世界高频闪烁。较大的石块用少量几何，细砾主要由法线和粗糙度表现。

## 驼队、云与远景

- 驼队先选第一馆上坡／过岭，以及进入谷地后仍能看见的远方山脊。建议6–8只，距主路线约120–250米，排成不完全等距、略有折线的队列；若被沙丘遮挡则合理露出或消失，不固定贴在屏幕上。
- 很远且只需轮廓的驼队可用透明图卡；更近、会绕行看到侧面或需要稳定地面投影的驼队，用低面数模型更稳。已有骆驼GLB可作为后续候选，不能把原高细节多只复制而不评估成本。
- 高空云层可用透明图卡、分层天空贴图或天空背景；无需为每朵远云建复杂3D。所有远景图卡需处理透明边缘、朝向和与天空的色差，避免像贴纸。若云不设计投地影，便不增加大范围动态云影。
- 本次实际收到的两张附件是岩石／地貌参考，未收到独立驼队或云图。原附件临时路径读取不可用时只登记为对话中已查看，不能假称归档成功。
