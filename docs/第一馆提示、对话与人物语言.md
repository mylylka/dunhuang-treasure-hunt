# 第一馆提示、对话与人物语言

整理日期：2026-11-06。范围：第一馆独立试玩中的 3D 探索、壁画带看、藻井观察、画架设色与画卷解锁；另收录从画架进入填色时的关键往返提示。

本文记录当前接入的运行文案及其触发位置，便于后续统一审阅台词、提示和配音。第一馆角色语言目前以屏幕字幕呈现，尚未接入人物录音；首次解锁画卷时另有一段短音效，它不是语音。

画卷解锁后会进入共用的纹样主题。本文收录第一馆专属提示，以及从馆内画架进入《飞天持莲》填色的提示；不重复列出解锁后各个通用 2D 玩法和其他关卡的全部文案。

## 自由探索时的角色发现语

玩家在互动点附近停下来约一秒后，系统可按首次发现播放简短字幕，并让小旅人转向对应目标。行走时会中断当前短句。

| 对象 | 角色字幕，按顺序 |
| --- | --- |
| 藻井 | “最上面的小方格里，好像藏着几只兔子。” → “咦，它们的耳朵……怎么有点奇怪？” |
| 画架 | “咦，这儿还有一幅画？怎么一点颜色都没有啊？” → “旁边还有颜料呢……要不我来试试？” |
| 画卷台 | “三项发现都齐了！这卷纹样游戏也打开了。” |

短句字幕旁有“跳过”按钮；点“跳过”会结束当前这组短句。藻井附近的互动按钮显示“抬头看看”并标出 F。

**触发备注：**画卷台这句的内容表示三项发现都完成，但当前事件代码没有检查解锁状态，也没有把这句记入跨次访问记录。因此它可能在通关前首次停留于画卷台时出现，并在重新进入场景后再次出现。文案与触发条件不完全一致。

## 壁画：邀请、自动带看与借物补画

### 邀请玩家

玩家首次走到壁画约六米外的观察位，会看到邀请文字和两项选择。第一次默认文字为“前面有一面壁画，要过去看看吗？”；选择：

- **玩壁画**：系统接管移动与镜头，先带小旅人到观察位，再依次看壁画、桌案和壁画全景。
- **自由探索**：不播放带看。玩家离开观察位后，地面才出现一个微弱发光的小圈；之后可回到小圈重新接受邀请。

已经修复完整后回到观察位，邀请文字改为“要再看看这面壁画吗？”，按钮为“再看一遍”和“自由探索”。首次拒绝前不会出现地面小圈。

### 带看对白

| 镜头与动作 | 小旅人字幕 |
| --- | --- |
| 转向并观察脱落壁画 | “这面墙怎么都脱落了……原来画的是什么呢？” |
| 自动走向桌案，镜头逐渐看清桌面 | “这边有莲花……” |
| 镜头继续扫过桌案，看到鸟等实物 | “这些东西会不会跟画有关呢？” |
| 回到壁画全景前 | “我再去看一眼壁画吧。” |
| 返回观察位，开始请玩家找纹样 | “嗯，好像真的有关系。中间这个会不会是莲花？” |
| 莲花提示停留一小段时间后 | “点一下桌上的莲花试试。” |
| 后续自由观察鸟、葡萄纹样 | “仔细看一看，猜一猜。画面上还缺什么呢？” |

选择壁画后，玩家移动被接管，人物身体和头部会朝当前叙述对象转向，镜头依次呈现墙面、桌面、鸟和回望壁画。带看返回观察位后，玩家可直接点桌上的实物；找鸟和葡萄时不提前说出答案。

带看期间点击 3D 画面可快进当前可快进的短句，不会把同一次点击误作实物选择。每轮修复使用“实物唤醒 → 丝绸状纹光流向壁画 → 壁画纹样显影”的效果；无需另玩拼合小关卡。

### 点选反馈与逐项科普

| 情况 | 显示文字 |
| --- | --- |
| 点错实物 | “再对照一下墙上的轮廓，试试另一件物件。” |
| 点到已修复的实物 | “这件已经找到对应的纹样了，再看看下一处。” |
| 本轮修复保存失败 | “这处暂时没能保存，请再点一次试试。” |
| 莲花纹显影后 | “莲花常常被画成围绕花心展开的纹样，既像真花，又比真花更整齐。” |
| 飞鸟纹显影后 | “飞鸟纹常常会排进边饰里，和其他纹样一起重复出现。” |
| 葡萄藤纹显影后 | “像葡萄藤、卷叶这样的纹样，常常顺着方向连续展开，组成一整条装饰。” |

逐项科普在对应纹样修复后出现。所有三处完成后，壁画再整体翻新，并一次性显示下面这段完整总结；它作为一个较宽的说明框，不逐句轮播：

> 敦煌壁画里的纹样，常常从花、鸟、果实等形象中提炼出来。莲花、飞鸟、葡萄，都会被画成更适合装饰的纹样。这些纹样又会用重复、连续、对称或旋转的方式排列起来，成为壁画和藻井中的美丽图案。

总结框中的“继续探索”用于退出带看。当前正常完成路径直接进入整幅总结，不会逐句轮播总述。

## 藻井：三兔共耳

靠近井心时，人物抬头看藻井。首次字幕为“抬头看看，最上面的小方格里，兔子们围在一起。”；选择“放大看看”后，原本天花板上的方形图案飞到画面中央放大，原场景虚化留在背景。选择“继续探索”或关闭图案可返回展厅。

| 互动进度 | 当前提示 |
| --- | --- |
| 开始 | “点一只兔子的身体，仔细看看。” |
| 已选一只兔子 | “再点另一只兔子的身体。” |
| 正在找当前兔子的耳朵 | “找找这只兔子的两只耳朵。”；选中一只后改为“再找找这只兔子的另一只耳朵。” |
| 第二只兔子双耳点齐 | “原来这两只兔子共用一只耳朵。再点最后那只兔子的身体。” |
| 完成 | “三只兔子两两共耳，图上只画了三只耳朵。” |

按发现轮次，每只兔子的轮廓分别使用金、红、蓝描边。共用耳朵保留各轮颜色的叠加描边。完成时附加说明：“莫高窟第407窟的藻井中，三兔绕井心同向奔跑。”

异常反馈：重复点击已选位置时显示“这处已经点过了，再看看另一处。”；点击非目标位置时显示“再沿着兔子的轮廓看一看。”；点画面其他位置时显示“直接点画上的兔身或耳朵。”；保存失败时显示“这条手记暂时没有保存。再点一次最后那只兔子试试。”；井心图未能加载时显示“井心图暂未载入。返回展厅后可以再试。”

## 画架与填色

### 走近画架

首次停留画架附近时，小旅人依次说：

1. “咦，这儿还有一幅画？怎么一点颜色都没有啊？”
2. “旁边还有颜料呢……要不我来试试？”

点“给画添点颜色”后，画架面板说明根据状态显示：

- 尚无作品：“画稿和颜料都准备好了，试着给它添上颜色吧。”
- 已有作品：“这幅画是你的创作。可以静静欣赏，也可以换一幅。”

相关按钮为“开始设色”“再画一幅”“欣赏当前作品”“从作品库更换画作”。空作品库提示“还没有收藏。完成一幅填色作品后，它就会出现在这里。”；作品列表可用“查看更多作品”。

### 3D 画架进入 2D 填色，再自动回到 3D

从第一馆 3D 画架打开《飞天持莲》后，填色页显示“飞天持莲”，操作提示“选色后点区域，放大可拖动”。提交按钮为“完成作品”，保存中显示“正在保存作品…”。完成后临时显示“作品已保存，正在返回院内画架…”，随后返回原来的 3D 位置，新作品挂到画架。小旅人接着说：

1. “哎？真的挂上去了！作品也收藏好了。”
2. “不同的色彩和深浅，让中心和边饰更鲜明。”

### 从普通 2D 入口完成填色

普通 2D 入口完成后留在结果页，不跳入 3D。提示为：“可以到 3D 世界的画架，从作品库选择这幅画来展示。”

填色关卡资料显示：标题“飞天持莲”；副标题“自由填色 · 配色参考”；目标说明“自由选择颜色，为持莲图案着色；可以查看配色参考，也可以创作自己的配色。”难度“自由创作”。

填色页的常用文字还包括“选色后点区域，放大可拖动”“参考配色”“参考配色不作为评分标准”“继续填色”“1× / 2× / 3×”“完整色盘”“自由选色”“擦除”“撤销”“清空”“已着色 N 个区域”“正在准备填色区域…”“正在保存作品…”“正在展示你的作品…”。参考图被标为“AI教学示意”。

## 三项完成后的画卷解锁

借物补画、三兔共耳、画架设色首次全部完成后，系统播放短促华丽音效，小旅人停下并转向院子西侧的画卷台，镜头沿玩家当前距离和位置取景。桌面画卷光效从无到有、自下向上显现并持续旋转。字幕为：

> 发生了什么？

随后系统尝试沿院内可行路线带小旅人步行到画卷旁，首次显示正式通知：

> 第一馆通关！游戏世界已开启。

通知按钮：“继续探索”。如玩家选择跳过自动带路，或当前位置无法规划出院内通路，显示：“第一馆通关！院子西侧的画卷已亮起，走到桌前点击画卷即可进入游戏世界。”按钮仍为“继续探索”。

之后画卷保持常亮，不再重复强制仪式和通关通知。靠近画卷可点击“进入游戏世界”；未完成三项时打开画卷说明：“完成借物补画、三兔共耳和画架设色，这卷纹样游戏就会打开。”

## 当前未接入流程中的旧文案

- `GALLERY_INTRO` 中保存着旧壁画初见句“这面墙上的图案，怎么缺了几块？”和“旁边这些实物，好像也藏在壁画里。靠近桌案看看吧。”当前运行时不会从自由探索短句队列播放它们；壁画改由观察位邀请和系统带看流程处理。
- `src/app/FirstGalleryPuzzles.tsx` 中保留早期壁画碎片拼合小关卡的题干、提示和按钮，但它没有接入当前第一馆运行流程。当前按“省略小关卡”设计，玩家在观察位直接点桌上实物，纹样飞向壁画。
- 壁画模块仍有备用句“三处纹样都找到了，壁画又连成一幅了。”正常三轮完成流程转入整幅总结；这句 `complete` 阶段文字目前不是正常流程里的实际台词。
- 第二馆“哪里来的音乐声？”等台词属于其他场馆，不属于第一馆文案。
