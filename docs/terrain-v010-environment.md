# 世界环境正式接入 v010

用户于2026-11-03认可环境样片v002，并授权继续接入。此版本保留三馆建筑、交互、路线、湖形和已有可行走区域的高度；不改2D玩法。旧v009构建、Blender样片v001/v002均保留。

## 实施结构

- `environment-layout-v001.ts`提供外围连续沙丘、网格采样和实际三角面高度。整个原可走边界内的高度函数保持不变，岩群与驼队完整范围位于边界外，并留跟随镜头缓冲。
- 第三馆东侧及东南侧为有疏密的风蚀岩群。复用已批准的岩体形态，岩脚重新按当前游戏地形贴合，不直接搬入样片的整块地面。
- 第一馆至第二馆途中可转向看见南侧沙脊上的七只远方骆驼；保留真实比例，以天空衬托轮廓。当前是不同步态定格的氛围队列，不新增实时迁徙系统。
- 沙砾与戈壁使用已批准贴图派生的四张运行图、独立世界区域控制图和中尺度表面变化。沙砾仍以砂土为主体，戈壁另有硬土和扁碎屑。区域图不作短周期平铺，细节在远处淡出以减少颗粒闪烁。
- 固定西北315°、离地平线30°太阳。加载完成后、玩家操作前，计算全局静态投影及三馆细节投影；正常帧只更新角色小范围阴影。太阳方向不随镜头移动，湖面高光沿用同一方向。
- 新版高空镜头扩到外围岩群与南侧驼队，远雾从950米渐变到1900米，避免旧近景雾距遮没新增景观。旧预览保留原镜头与雾距。
- 旧玩法地形的横向狭脊仅在边界外115米内平滑消退，远丘带各自轻微错位，避免将同一窄脊无限挤出到远景。岩群接地按最终高度重新导出；驼队局部沙脊保持。

## 版本与重建

运行素材为`public/assets/world/environment-world/v001/`，Blender源和导出记录为`art-source/world/models/environment-world/v001/`。运行组件均以`terrain-environment-`命名。`terrain-v010.html`与默认首页启用独立环境版本标记，旧版本入口不启用此标记。

新增构建入口：`node scripts/build-terrain-v010.mjs`。本地独立试玩：`node scripts/serve-terrain-v010.mjs`，端口4223；旧4222预览保留。

## 验证边界

只验证新增材质/静态阴影的真实WebGL编译、可走地形保持、资源加载释放、高空及三馆相关视角、驼队轮廓、短程移动和阴影缓存次数。类型检查及本版本构建覆盖整合错误，不跑2D或全套E2E。构建图与诊断放`work/world/`，交付在`outputs/terrain/v010/`。

## 本轮结果（2026-11-04）

- `npm run typecheck`及本版本独立构建通过。
- `tests/world/environment-layout-v001.test.ts`三项针对性检查通过；全部道路采样、保留的边界和建筑平台高度不变。模型生成核对另覆盖17,576个原区域采样点。
- 实际Chrome场景完成入口、总览、坡顶驼队、下坡驼队、东侧岩群和大厅六处截图。七只驼队以天空衬底，岩群未与它重叠；岩脚按真实网格闭合接地。
- 六个新增运行资源加载成功，无页面/着色器错误。短程跑步和转头后静态阴影次数保持4，不随角色位置重复生成。静态图与角色图合计约40MiB显存。
- 室内半球补光设为0.95，主太阳强度仍为2.4。全局粗图有独立的深度余量；三馆细图保持较小偏移，保留柱脚接触关系。
- 这是桌面Chrome专项验证，不代表全设备性能验收。驼队当前为静态姿态；本轮没有开发实时迁徙动画。

完整报告及实景图：`work/world/terrain-environment-v010/`。可用`node scripts/verify-terrain-environment-v010.mjs`复查本轮六处，`--pilot`只做入口与总览。
