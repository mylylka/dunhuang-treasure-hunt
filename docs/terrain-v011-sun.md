# 太阳方向调整 v011

用户以高空总览画面的红圈指定太阳的水平来向。按该视角、场景中心及红圈位置估算，太阳方位设为约250°（北为0°、顺时针），即西偏南；高度角保留30°。这是从画面估算的方向，不将红圈当作地面上的太阳位置。场景静态与角色动态阴影、湖面高光使用同一方向。

新预览`outputs/terrain/v011/`，构建运行`node scripts/build-terrain-v011.mjs`，本地预览`node scripts/serve-terrain-v011.mjs`（4224）。v010独立预览与历史方向保留。改动后仅进行类型检查、构建及总览、坡顶、崖前、绘彩馆大厅的光影检查；不运行全量测试。
