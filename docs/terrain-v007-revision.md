# 庭院小工作坊 v007

依据用户本轮6处批注及“真实、有机、可开始作画”的陈设要求调整。院落模型另存courtyard/v006，网页另存terrain/v007；保留所有旧版本和原GLB。

工作桌为中心，小幅转向；玩家从院门方向进入桌前工作位。颜料架置于左手侧，正面向着工作区；纹样展示板斜对操作者，避免被桌面挡住。已有颜料碗、画板和笔形成工作桌面，加入用户的三灌木组合收住西前墙角。三个主要物件不排成一列，不增加新的绘画玩法。

最终source坐标：桌(-19.00,-3.45)、转10度；作画站位(-18.90,-1.30)；架(-23.05,-1.85)、高1.5米、正面yaw90度；纹样板(-20.70,.35)、高.982米、正面yaw120度；灌木(-22.65,.55)、整组高.85米。桌面复用原纹样贴图作为临摹稿，画稿与笔放在操作者一侧，颜料碗靠桌内侧错落布置。新模型测量JSON记录独立陈设的真实旋转多边形碰撞与作画、取色、看样通路；旧东侧牌/架位置释放碰撞。

已查明旧中央桌撑位于两排桌腿之间、没有端部连接，需要两道跨腿短撑与中央撑共同闭合。原桌腿最低Y=0，院砖顶约.003，几何并非悬空；接触阴影须另查。墙脚顶面比墙体突出2厘米，产生极细强亮边；修复接触几何和角部，不能只遮盖白线。

实际处理：新桌面、4腿、2道短撑与中央撑共8件实体形成连接整体，几何接触误差小于1微米；四脚嵌入地砖3毫米。仅该桌组保留模型原双面投影行为，其他建筑继续使用已确认的背面投影策略。四面保留围墙的实体底面抬至.5米，与同厚墙脚顶面严密相接，去掉原2厘米顶台；不修改全局阴影偏移来掩盖接缝。
