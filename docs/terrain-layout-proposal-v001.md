# 连续沙坡与月牙谷地改造方案 v001（已批准实施）

2026-11-02。本对话后续仅开发3D漫游；2D小游戏与文化教学内容由其他Agent负责。用户总览图已原字节归档在 `art-source/world/terrain-layout/v001/`。本方案按画面左→右组织空间，不把创作组合当真实地理复原。

## 结论

可以直接生成连续地形，并复用现有建筑与角色。建议先交付**带现有建筑的可行走地形样片**：先验收上坡、翻坡、下坡、湖湾与崖壁的距离和高差，再细化地表纹理和植被。建筑已完成，不必重新用方盒搭一轮；地形样片也不必做纯灰色。先用简洁沙色让坡面形状清楚。

坡顶遮挡采用真实坡面自然遮挡。用户指出离下坡坡缘稍远就看不到低处建筑，这个判断成立：按实际跟随镜头高度和整栋楼屋顶校准即可。走近坡缘，先看见远处地形/湖面的一部分，再逐渐看见楼顶和完整建筑。下坡道路沿侧坡弯下，不要求玩家从坡缘陡落处直走。

## 地势与空间（首版建议值，可在样片中调整）

以湖面为0米；X轴从参考图左向右，Z为前后。坐标用于规划，不是已经发布的地图。

| 区域 | 建议地势 | 体验与位置 |
| --- | --- | --- |
| 纹彩院半山腰 | 建筑基面约26米 | 左侧较宽的沙坡中上部，院落局部平缓；后方/右侧仍向坡顶升高 |
| 院落右侧坡顶 | 最高约40米 | 连续宽缓坡脊，不能堆独立尖山；院落附近看不到坡下乐舞坊 |
| 中央谷地 | 湖面0米、岸边约1～3米 | 开阔低谷；湖面始终水平，湖床与岸坡连续 |
| 乐舞坊 | 基面约2.5米 | 月牙内弯的平缓沙洲，按现有完整建筑留约60×50米缓冲区，不缩小正式建筑 |
| 右侧崖前 | 基面约10米 | 从谷地缓慢抬升；楼前台阶仍升高6.855米 |
| 高崖 | 顶部约68米 | 现有岩壁与九层楼整体搬迁、转向，楼正面朝左侧谷地 |

首版两院平面距离约180～200米，乐舞坊到崖口约180米。湖湾连同岸地暂预留约120×90米，水面本身按用户反馈做舒展、两端收尖而中段饱满的月牙：减小弯曲度，不做回包的马蹄形，也不收成过细的水带。轮廓和内弯按正式建筑实际边界细调。这是美术构图中的创作湖泊，不声称真实月牙泉测绘尺寸。水色较初版小样加深，保留浅岸渐变。

院落附近跟随镜头约30.5米，乐舞坊屋顶约20.3米。两者之间40米的坡脊足够遮住屋顶；不需要额外的建筑隐藏开关。从院门和出发道路，按实际跟随镜头确认坡缘自然遮挡即可。

## 道路与探索节奏

1. 从纹彩院真实院门出发，在山腰沿弯曲石板路向右上行，上升约14米。
2. 翻到坡顶附近，视野自然展开。前方坡缘可以较陡，可行走道路从侧面弯下；下降段以连续缓坡为主，避免做成长楼梯。
3. 下到湖湾后转沿湖岸，到乐舞坊真实院门。湖与建筑间留观景空间，湖岸不靠大量巨石阻路。
4. 从湖湾沿曲径走向右侧崖前，再走原来的台阶入洞。九层楼/门洞/内室/壁画/佛像保持原来的相对组装关系。

示意路径约480米，加上实际门口接驳和缓坡调整，预计约500米。按现有速度纯行走约4.5～5分钟、连续跑步约2分钟（未计停留与文化事件）。不为了拉开距离扩大成漫长空地。

道路目标：主要坡段约8～12°，短段尽量不超过15°。草案折线下坡局部18～19°需要在生成样片时延长弯道、均匀分配下降，不能直接拿草案点连出最终路。完整路宽、两侧路缘和每块石板都随坡面变化，最后一段必须接真实门口。

## 实施方式

- 一份连续高度场定义左坡、坡脊、谷地与崖前。地面网格、脚底高度、石板路、植被落点和镜头防穿地共用同一高度数据；控制大范围起伏，不用随机尖峰噪声塑造主要地势。
- 三处建筑各自保留本地坐标。建筑、台阶、碰撞、观察镜头、声音源、互动范围、安全返回点共同套用区域平移/旋转，避免只搬可见模型而漏掉触发点。
- 院落模型自带外部树石和道路，这些附属节点需要单独重新落地，不能随整栋院落抬高后悬空。
- 右崖组件保留原6.855米内外高差。用户实屏批注进一步将整组移至右前方红圈，根坐标约`(330,10,90)`，转向-160°，门面朝箭头所指的左后方；洞口渐显、佛像讲述和两侧故事判断使用转换后的本地区域坐标。
- 规划JSON的区域锚点是原模型根节点，顺序为`[x,y,z]`；路线草案顺序单独标注为`[x,z,height]`。实施布局统一使用具名`{x,y,z}`，真实院门、台阶入口、建筑局部平地均由区域变换计算。崖壁、九层楼和外部入口根高程为10米，内室/佛像根高程为16.855米。
- 月牙水面只用单一水平水位；湖底与岸边由同一轮廓生成。第一版不新增游泳机制，湖岸有与可见岸线一致的通行边界。
- 远山采用低面数远景轮廓和空气透视；不建造一整片可攀爬群山。近处保留现有确认过的树灌木与少量岩组。
- 新布局使用独立版本、会话键与预览端口。已经验收的旧版本可随时比较；正式默认地图切换另行确认。

## 分两步验收

**第一步：空间样片。** 复用正式建筑、人物、树与灌木，先有可行走的连续沙坡、简洁沙地、贴地道路与湖面；提供高空总览和从院门连续步行到谷地/崖口的实际画面。验收地势、距离、自然遮挡、坡度、建筑落地、镜头及三场景触发。

**第二步：地表完善。** 在第一步确定的地形上补沙纹、湿岸、植被疏密、远景层次和水面细调。避免地形反复调整时重复装饰工作。

水样另见 `docs/terrain-and-water-study-v001.md`。它用于先验收近处静水的材质方向，水样中的建筑尺度和岸边摆放不代表最终谷地布局。

## 通过条件

- 高空清楚看到半山腰院落→更高坡脊→低谷月牙湖→高崖楼的层次。
- 院落附近看不到乐舞坊，走近坡缘并下行时逐步出现；以真实坡面遮挡验证。
- 上中下坡是连续可行走地面；走/跑/停步、横屏触控和跟随镜头不穿地、不突然跳高。
- 三个区域的实际入口、原文化事件、故事、音频与安全返回点搬迁正确。
- 所有旧源图、模型、工程和已验收预览保留；本轮不接管2D开发。
