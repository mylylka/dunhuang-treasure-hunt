# 莫高窟 v004：浅色协调与山脚积沙

本轮按用户反馈只修整外立面色彩和接地：浅黄石面向现有沙漠的暖米黄靠拢，洞口、岩缝和纹理暗部保留；用Blender中的低矮、宽缓积沙覆盖底缘，使岩体像从沙土中露出。保持主台阶、洞窟内室、道路走向、角色和小游戏。

目录约定：新源工程和材质处理登记放`art-source/world/models/mogao/v004/`；运行外部模型放`public/assets/world/mogao/v004/`；脚本`build-world-mogao-v004.py`；地面采样放`src/content/world/mogao-surface-v004.json`；独立预览`mogao-v004.html`构建到`outputs/mogao/v004/`，端口4206。内室和布局复用v003。v003及用户FBX/贴图原件不改、不删除。截图、日志和对比保存至`work/world/mogao-v004-*`。

材料使用受暗部保护的确定性调色，不重新生成贴图内容、不提高全场曝光。积沙采用少量明确设计的宽缓隆起合并为连续网格，外缘缓缓沉入原沙地，避免一圈等高裙边；主通道留空。Three.js仅加载模型并读取对应地面采样，不生成地形几何。以真实网页同机位远景、入口和侧面近景确认颜色、边缘及进出通路。
