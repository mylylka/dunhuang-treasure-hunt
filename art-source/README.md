# 原稿与参考资料约定

此目录保存婧婧在 ChatGPT 网页端生成并提供的游戏美术原稿、真实教学参考及交付与来源记录。当前素材索引共28项：15项 `user-art-v001` 游戏美术和13个教学素材ID。教学原件分批归档：v001共12份，v002新增2份无叠加水印来源照片；其中第329窟照片导出总图和井心两个运行ID。索引数量、原件数量和当前展示数量分别记录，不混为一谈。

真实照片、整理图和拼版不标为AI生成。面向玩家的游戏美术署名使用“开发者”；归档记录保留婧婧及原摄影、供图、发布机构的真实信息。旧几何SVG、带水印旧参考与旧运行图均保留，不覆盖、不删除。

## 原15项AI美术交付

- “游戏第一版本图样”文件夹提供14张PNG：U01～U05、五枚U06图标、T01～T03和L02。
- 首关A图另在Downloads中，原名“L01第一关 A 图.png”，已与其余素材一并归档。
- `delivery-v001.json` 保存每项素材原名、归档路径、原尺寸、alpha状态和SHA-256；按钮还登记透明留白裁切范围。
- 原始提示词与生成过程本次未随图提供，不补写或推测。
- 完整15项文件与尺寸表见[美术接入说明](../docs/art-assets.md)和[素材交付清单](../outputs/素材交付清单.md)。

运行素材文件名采用英文kebab-case；来源归档允许保留源站与用户原文件名用于追溯。版本号递增，同一版本原稿不得覆盖；新来源另建版本。来源记录不写入账户、token或密钥。

## 原稿与运行文件分开

L01/L02及T01/T02/T03原稿均为1536×1024，运行版为1200×800。共享运行图位于 `public/assets/shared/`，封面位于 `public/assets/themes/`，首关位于 `public/assets/levels/patterns-intro/`，教学图位于 `public/assets/lessons/patterns/`。原稿完整保留。

`python3 scripts/import-art-v001.py` 重建原15项AI美术；`python3 scripts/import-pattern-lesson-references.py` 重建v001参考；`python3 scripts/import-pattern-lesson-references-v002.py` 重建本轮v002参考及井心裁切。脚本使用已有Pillow，核对归档内容，不覆盖不同内容的旧原件；v001脚本不降级已采用v002的索引。正常游戏运行与npm开发构建不依赖Python。

运行版B以A为底，仅在五个配置区域内用物象蒙版合入L02，区域外像素与A一致；用于排除原稿的额外重绘漂移，不生成或重画内容。教学参考只做格式转换或记录在案的原像素裁切，不放大、调色、补画或去水印。九宫格和蒙版细节见[素材接入说明](../docs/art-assets.md)。

## 后续素材与记录要求

悬浮教学面板、六关目录和结果页复用现有面板、按钮、背景与程序排版，不需要新装饰稿。第2～6关A/B仍待制作；每关先确认完整A图，再局部编辑B，保留同尺寸3:2原稿，缩略图由A导出。拟设差异数随素材验收调整，见[纹样找不同六关计划](../outputs/纹样找不同六关计划.md)。

每次交付保留素材ID、原名、尺寸、格式、日期、SHA-256、来源、窟号年代与部位、处理方式、真实提供的提示词及授权说明。未交付或未核实的信息不补写为事实。

AI游戏图不是文物原貌复原，游戏中的乐器、佛像组合与配色变化不作历史证据。正式美术由婧婧生成和修改，Agent负责图源整理、规格、格式、坐标、局部合成与技术接入；内容性修图交回用户制作。

## 标题字体原件

`shared/fonts/v001/` 保存官方LXGW WenKai原始TTF、OFL许可证及source-notes.json；运行端只使用“敦煌寻宝记”五字WOFF子集（3048字节，内部名Dunhuang Title），位于 `public/assets/shared/fonts/`。不安装系统字体、不依赖外部字体服务。字体来源、原件和子集SHA、导出方法均已登记；重建脚本为 `scripts/import-title-font.py`。正常npm构建使用已经导出的字体，不依赖Python。
