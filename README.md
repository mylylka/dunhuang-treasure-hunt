# 敦煌寻宝记

面向高中生的敦煌文化网页小游戏合集。当前实现公共框架、文化导览及10个正式关卡：3关找不同、4关自由填色、3关拼图。素材索引登记47项：原有28项、两关找不同新增4项、四关填色新增12项、三关拼图新增3项。原稿与处理记录按版本保存；AI游戏图、教学实物照片及开发者交付的拼图参考分别登记。

技术：Phaser 4.2.1 + React + TypeScript + Vite。依赖版本由 package-lock.json 固定。

游戏采用一屏一个场景：首页、主题选关、游玩、结果通过按钮切换。游戏图与操作区按当前视口的宽和高共同适配，可使用只读的“放大观察”比较局部；长文字说明在独立面板内阅读，不靠向下拉动网页完成游戏流程。

界面分为：首页选主题 → 文化教学 → 选择游戏 → 该游戏的关卡 → 游玩与结果。“纹样与色彩”已加入七屏可交互悬浮标签文化导览（外框与浅色内容安全区分层），以实物照片讲解装饰部位、花叶、几何、动物、组织方式、色彩和六题知识小考。每次从首页进入主题都先显示导览，顶部始终可直接玩游戏；教学与小考不作为游玩前置。学习记录和游戏记录独立保存。

“纹样与色彩”只显示找不同、拼图、填色。找不同已开放藻井寻踪、莲瓣与团花、忍冬与卷草三关，每关5处差异；六关计划的后三关明确标记筹备中。填色已接入三兔莲花、莲花茶花、葡萄石榴、葡萄莲花四关；拼图开放莲花平棋、三兔飞天、双龙藻井三关，六关计划的后三关标记筹备中。三个玩法均可从游戏选择进入。首页三张封面采用相同3:2图框，标题紧随图片；关卡目录按玩法分页。正式关卡的封面、标题和按钮均可点击或用键盘进入，筹备位不生成链接；拼图目录按钮始终为“开始拼图”，结果页保留“再拼一次”。结果页在主体显示文化参考与本关图像来源说明，不逐条分析差异。找不同的参照图A、变化图B采用HTML文字，按画布布局定位，保持清晰。

填色页同时显示大幅线稿画布与较小的参考配色图，参考图保持完整比例并可点击放大。三兔莲花、葡萄石榴、葡萄莲花已换用2026-10-29重新交付的配色参考；关卡封面共用新版，线稿、区域图和旧作品保持原版本。玩法选择里的填色封面采用横版满幅cover，仅封面允许裁切；实际游玩和参考图完整显示。

填色采用自由配色：每关提供12色与自定义选色、擦除、撤销、可撤销的清空重涂、参考配色，以及1～3倍缩放和拖动。至少着色一个有效区域后可主动完成作品，不要求填满细碎区域，不按参考颜色判分。作品预览和PNG导出共用颜色与线稿合成方法；区域颜色单独保存在本地，不存图片base64。点击着色约200ms柔和过渡，减少动效设置或系统偏好生效时立即换色。

新增找不同保持1254×1254原生方形，旧首关保持3:2；比例由素材尺寸派生。`scripts/import-pattern-levels.py` 可复现配准与局部合成，两关B在5组确认区域之外与A逐像素相同。忍冬卷草B采用v002圆润红瓣，整圈各瓣共同算一处差异；原稿与旧运行图保留。填色原稿保留；用户本轮另行授权三兔莲花、葡萄莲花按配色参考局部补线，两关v002已局部合成并重建区域图，补线范围外0像素变化。三兔345区、莲花茶花511区、葡萄石榴611区、葡萄莲花510区；区域数量不作为完成度。补线配方 `scripts/import-coloring-repairs.py` 可从正式归档重建，不依赖work缓存。整体验证结果以开发验收记录为准。

拼图中，莲花平棋采用3×3原位旋转，每次点击顺时针90°；三兔飞天为12片、双龙藻井为20片的不规则凹凸拼片，邻边使用互补曲线。可拖拽或选片后点击目标，正确放置才吸附，全部复位才完成。空位不显示碎片轮廓线；主动点击提示时才高亮目标位置，并将对应碎片滚入可见范围，提示不会自动解题。碎片区独立纵向连续滚动，桌面可用滚轮，手机从碎片区空白处上下滑动，也可使用右侧滚动条；整页、拼图区和底部操作保持固定。横竖屏切换保留本局，退出重进重新开始。前两关完成后可点“下一关”进入下一个实际开放关，末关不链接筹备位置。

三个拼图JPG及带水印的v001运行图完整保留。按用户本轮授权，当前v002游戏图仅在右下水印区域采用内置imagegen局部补绘，登记范围之外0像素变化；采用的 `retouch-candidate-detail.png` 局部候选、提示词及两个小范围存于各关 `art-source/levels/<level-id>/v002/`，早期全图候选仅归档而未采用。`node scripts/prepare-puzzle-retouches.mjs` 可从局部候选与v001运行图重建，不把补绘细节当作文物考据。莲花平棋的文化参考已改用用户指定的新浪页面，原始图片来源与参考信息分别登记。

## 直接试玩

双击 `outputs/启动敦煌寻宝记.command`，打开 http://localhost:4186 。这个脚本使用已有 Node.js 服务 `outputs/web/`，无需再次安装依赖。关闭启动终端可结束该预览。

## 继续开发

先读 AGENTS.md。依赖缺失时运行 `npm ci`，随后 `npm run dev`。增加已支持玩法的关卡，在 `src/content/levels/` 加 JSON 和素材登记即可。玩法规则与主题、关卡内容分别维护。

## 验证

```sh
npm run validate:content
npm run typecheck
npm run test
npm run test:e2e
npm run build
npm run test:production
```

E2E与生产浏览器检查串行执行，避免重图像任务争抢本地资源。浏览器运行时放在项目 `work/browsers/`。当前 macOS 如已安装 Chrome，测试直接使用它；其他环境可先运行 `npm run test:browsers` 安装项目内浏览器运行时。WebKit 也由该命令准备。不安装全局包或修改系统设置。

构建输出 `outputs/web/`；构建工具不自动删除输出中的旧文件。交付时可将本项目自身产生的旧构建文件移至 `work/build-history/` 保留，用户原稿不覆盖或删除。

## 文档

- `docs/architecture.md`：代码、内容与进度边界。
- `docs/art-assets.md`：AI美术、教学参考图及图源更新、比例、切片和素材替换。
- `art-source/README.md`：用户原稿及参考资料的版本约定。
- `outputs/使用说明.md`、`outputs/素材交付清单.md`：用户交付入口。
- `outputs/拼图六关计划.md`：三关拼图内容及另外三关筹备位置。

当前没有服务器账号、云同步或公开部署。每个设备浏览器独立保存记录。其余主题展示制作中说明，测试关不会出现在正式列表。

首页使用本地霞鹜文楷标题字形子集，以朱砂色呈现大号“敦煌寻宝记”，入口题名为“开启敦煌探索”。所有教学图都有统一的放大观察窗，可全图、2倍、3倍观察并拖动或按方向键移动；有局部区域时另外提供“看重点”。六题小考覆盖前六屏，题目区独立滚动，答错可查看解释并交卷，跳过不伪记学完。
