本分支 `codex/3d-world` 的第一阶段3D灰模曾提供：默认入口 `#/` 可行走、观察藻井、进入已有教学并安全返回，还可验证两段九色鹿故事播放器。当前游戏世界的主题选择入口为 `#/themes`。操作、验证及阶段边界见 [灰模试玩说明](docs/3d-world-graybox.md)，模型及素材规范见 [3D素材约定](docs/world-asset-contract.md)。

技术：Three.js 0.187.0 + Phaser 4.2.1 + React + TypeScript + Vite。正式3D模型使用Blender制作；依赖版本由 package-lock.json 固定。

游戏采用一屏一个场景：首页、主题选关、游玩、结果通过按钮切换。游戏图与操作区按当前视口的宽和高共同适配；找不同直接在主画布同步缩放、移动并点击差异，教学、拼图参考、填色参考及影子对照保留各自图像观察能力。长文字说明在独立面板内阅读，不靠向下拉动网页完成游戏流程。

## 直接试玩

日常手机和电脑试玩运行 `npm run dev`，电脑打开 http://localhost:5173 ，同一 Wi-Fi 的手机使用电脑的局域网 IP 和 5173 端口。2D 使用首页，3D 可打开下方列出的展馆入口，共用 `public/` 素材。需要测正式压缩、缓存和手机加载性能时，运行 `npm run build` 与 `npm run play`。加载与二维空洞修复记录见[性能修复记录](docs/hidden-object-loading-v001.md)。

双击 `outputs/启动敦煌寻宝记.command`，打开 http://localhost:4186 。这个脚本使用已有 Node.js 服务 `outputs/web/`，无需再次安装依赖。关闭启动终端可结束该预览。

先读 AGENTS.md。依赖缺失时运行 `npm ci`，随后 `npm run dev`。增加已支持玩法的关卡，在 `src/content/levels/` 加 JSON 和素材登记即可。玩法规则与主题、关卡内容分别维护。

## 验证

按本次改动选择相关命令，不将以下清单视为每次必须全跑的流水线；测试收集成功或历史记录不能代替当前版本的浏览器验收。

```sh
npm run validate:content
npm run typecheck
npm run test
npm run test:e2e
npm run build
npm run test:production
```

E2E与生产浏览器检查串行执行，避免重图像任务争抢本地资源。浏览器运行时放在项目 `work/browsers/`。当前 macOS 如已安装 Chrome，测试直接使用它；其他环境可先运行 `npm run test:browsers` 安装项目内浏览器运行时。WebKit 也由该命令准备。不安装全局包或修改系统设置。

日常 3D 试玩运行 `npm run dev`，在同一个 5173 端口打开 `/first-gallery-v001.html`、`/music-companion-v002.html` 或 `/mogao-exhibit-v001.html`。开发预览直接使用当前源码和 `public/` 共享素材，不生成试玩构建目录。

试玩期间关闭自动热更新，修改后手动刷新页面。需要在开发时开启热更新，可用 `DUNHUANG_DEV_HMR=1 npm run dev`。

需要留档时，给 `playtest:build` 指定新目录，再用同一路径启动静态试玩。已有快照可直接使用第二条命令。

```sh
DUNHUANG_PLAYTEST_BUILD=work/world/playtest-snapshot-v001 npm run playtest:build
DUNHUANG_PLAYTEST_BUILD=work/world/playtest-snapshot-v001 npm run playtest:serve
```

静态试玩继续从 `public/` 读取模型、图片和音频。只有明确需要离线携带时才制作完整包。`outputs/terrain/` 与 `outputs/*.zip` 为生成交付物，默认不加入 Git。

按需调试时，可用 `DUNHUANG_TEST_TRACE=1 npm run test:e2e` 为失败的测试保留浏览器回放。

`npm run playtest:prune` 预览已过期的回放和受管 2D 临时包，追加 `-- --apply` 才执行清理。回放保留 7 天，受管 2D 临时包保留 48 小时。临时包的专用目录、标记和暂留方式可用 `npm run playtest:prune -- --help` 查看。文件归档及旧 2D 文稿索引见[项目文件存放约定](docs/project-file-layout.md)。
