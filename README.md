# 敦煌寻宝记 · 2D 游戏

面向中学生的敦煌文化网页小游戏。首页选择主题后直接选择玩法与关卡。当前有三个主题、五种玩法和 22 个实际关卡：纹样与色彩包含找不同 3 关、拼图 3 关、填色 5 关；飞天、乐舞与服饰包含计时找物 9 关和影子配对 1 关；壁画故事包含《九色鹿王本生》12 幅画廊排序 1 关。关卡目录中的筹备内容尚未开放。

填色支持本地保存、金银材质与 PNG 导出；找物使用三章九关、按局随机生成的目标；九色鹿支持触屏拖动、键盘调整与完整长卷欣赏。完成记录和作品保存在当前浏览器。手机采用横屏，转为竖屏时保留本局并停止交互与计时。

## 开发与试玩

先读 `AGENTS.md`。依赖缺失时在项目目录运行 `npm ci`。日常试玩先检查 5173 端口，再运行 `npm run dev`，访问 `http://localhost:5173/`。开发服务默认关闭自动热更新，刷新页面取得改动；需要热更新时设置 `DUNHUANG_DEV_HMR=1`。

`src/content/levels/` 是关卡配置，`src/games/` 是玩法，`src/app/` 是界面，`public/assets/` 是运行素材，`art-source/` 是原稿及来源登记。内容素材和存档结构遵守项目约定，旧版本和原稿需保留。

## 验证

按改动范围选择执行 `npm run validate:content`、`npm run typecheck`、`npm run test` 和 `npm run build`。浏览器测试使用 `npm run test:e2e`，独立测试端口为 5174；按影响范围选择测试文件，浏览器检查串行执行。构建输出在 `outputs/web/`。
